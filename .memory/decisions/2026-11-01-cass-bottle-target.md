# Decisions: 생맥주잔을 카스 프레시 병맥주 타겟으로 교체 (Cass Bottle Target)

- Date: 2026-11-01
- Status: Confirmed

## D01. 타겟 교체 범위 및 병맥주 브랜드 선정
- **Chosen**: 적 타겟 중 체력 3 중형 지상 타겟인 '500ml 생맥주잔(`mug`)'을 '카스 프레시 500ml 병맥주(`bottle`)'로 1:1 교체
- **Rationale**: 캔 맥주 라인업에 비해 시각적 완성도와 매력이 떨어지던 생맥주잔을 오비맥주의 대표 플래그십 병맥주인 카스 프레시로 교체하여 타겟 라인업의 프리미엄 비주얼과 타격감을 높인다. 보스(생맥주 냉각기 디스펜서) 및 1인칭 발사대(생맥주 탭건)는 브루어리 펍 홀 테마와의 조화를 위해 그대로 유지한다.

## D02. 3D 유리병 비주얼 및 재질 모델링
- **Chosen**: 최신 '올 뉴 카스(All New Cass)' 스타일 (투명 유리병 + 내부 황금빛 맥주 액체 + 블루/실버 라벨 + 상단 은색 왕관 뚜껑)
- **Rationale**: 불투명하거나 어두운 갈색병보다 투명 유리 재질(`MeshPhysicalMaterial`, 투과율 및 굴절률 적용)을 사용하고 내부에 기포가 피어오르는 황금빛 맥주 액체와 상단 은색 크라운 캡을 조합함으로써 화면 내 시인성과 3D 렌더링 품질을 극대화한다.

## D03. 병맥주 전용 고해상도 라벨 텍스처 에셋 제작
- **Chosen**: Playwright 캔버스 렌더러 스크립트(`scripts/generate-labels.mjs`)에 카스 프레시 전용 1024×512 라벨 생성기 추가 및 `public/textures/labels/bottle.jpg` 정적 자산 서빙
- **Rationale**: 기존 캔 4종과 마찬가지로 오비맥주 카스 프레시의 다이내믹 쉐브론 로고, 쿨 블루 그라데이션, 실버 엠블럼을 반영한 고해상도 전개도 텍스처를 코드로 생성하여 오프라인 환경과 빌드 환경 모두에서 무결성을 유지한다.

## D04. 피격 및 최종 파괴(크러시) 시그니처 연출 및 오디오
- **Chosen**: 1~2타 피격 시 단단한 유리 타격음 및 표면 미세 파편/기포 + 3타 격파 시 경쾌한 "뻥!" 병뚜껑 팝 사운드와 함께 은색 크라운 뚜껑이 공중으로 솟구치고 투명 유리 파편 비산 및 황금빛 맥주 분수 폭발 파티클 방출
- **Rationale**: 병맥주 특유의 시원한 개봉감과 깨지는 타격 쾌감을 살려 플레이어에게 강력한 시청각 피드백을 제공한다. 사운드는 `SoundSynthesizer.ts`의 Web Audio API 프로시저럴 합성음으로 구현해 외부 음원 파일 의존성 없이 즉시 재생된다.

## D05. 코드베이스 식별자 및 데이터 모델 리팩터링
- **Chosen**: `TargetKind` 식별자를 `mug`에서 `bottle`로 전면 리팩터링 (`TARGET_SPECS.bottle`, `displayName: '카스 프레시 병맥주 (Cass Fresh Bottle)'`, 스폰 엔진, Three.js 모델 및 단위 테스트 동기화)
- **Rationale**: 겉모습만 바꾸고 변수명을 `mug`로 남겨두면 발생하는 코드 부채(Technical Debt)를 제거하고, 도메인 모델과 실제 타겟 간의 명확한 일관성을 확보한다. 기존 체력(3), 이동속도(2.3m/s), 처치 점수(160점) 등 검증된 밸런스 수치는 그대로 계승한다.
