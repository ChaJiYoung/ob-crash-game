# Decisions: 무기 스킬 개편과 효용성 정리

- Date: 2026-11-05
- Status: Confirmed

수치 근거는 실제 엔진을 임시로 패치한 봇 시뮬레이션이다(무기·조건별 100판 안팎, 클리어율 오차 약 ±10%p). 칼날·거품의 비행 시간은 무시하고 쟀으며, 사람 플레이 데이터는 아니다. 임시 패치는 저장소에 넣지 않았다.

## 전체 합산 결과 (D01~D17 적용, 시뮬레이션)
| 무기 | 클리어율, 아주 부정확 봇 (전 → 후) | 클리어율, 보통 봇 (전 → 후) | 클리어 평균 점수, 보통 봇 (전 → 후) |
|---|---|---|---|
| 샷건 | 88% → 82% | 100% → 99% | 17,775 → 17,672 |
| 리볼버 | 86% → 88% | 100% → 100% | 16,877 → 16,930 |
| 개틀링 | 89% → 90% | 100% → 100% | 15,446 → 15,240 |

모두 오차 안이다. 평소 난이도는 거의 그대로이고 스킬의 역할과 표시가 바뀐다. 역할은 뚫어뻥이 멈추기, 리볼버가 처치, 개틀링이 밀어내기다. 위 시뮬레이션에 평타 관통 표시(D13)와 설명 변경(D17)은 판정에 영향이 없어 포함하지 않았다.

## D01. 리볼버 스킬을 부채꼴 직진 칼날로 교체
- **Chosen**: 필드 전체 즉시 피해 + 둔화를 없애고, 칼날이 부채꼴로 곧게 날아가 닿은 대상만 맞힌다. 조준은 쓰지 않는다. 방향은 몬스터 등장 범위(좌우 `수평 시야각 절반 × FAN_MARGIN_RATIO`)를 칼날 수로 균등하게 나눈 고정 방향이다.
- **Rationale**: (사용자 선택) 지금은 피해가 시전 순간 전체에 들어가고, 칼날 장식은 최대 8.7m까지만 날아 대부분의 몬스터에 닿지 않으며, 몬스터별 타격 연출도 없어 "맞는 건지 모르겠다"가 나왔다. 조준을 안 쓰는 이유는 스킬이 '휙' 제스처이기 때문이다. 자동 추적(빗나감 0%)도 검토했으나 닿아야 맞는 느낌을 택했다.

## D02. 레벨별 칼날 수와 관통
- **Chosen**: Lv.1~4 칼날 3 / 3 / 5 / 7개, 관통 0 / 1 / 1 / 2. 칼날 하나는 최대 `관통 + 1`마리를 맞히고, 같은 대상을 두 번 맞히지 않는다. 여러 칼날이 한 대상을 맞히는 것은 허용한다.
- **Rationale**: (사용자 선택) 칼날 수와 관통을 레벨업 요소로 쓰자는 사용자 제안. 보통 봇 기준 스킬 1회에 맞히는 수가 1.44 / 2.07 / 3.27 / 3.76으로 레벨마다 늘어난다. 스킬이 통째로 빗나가는 비율은 Lv.1 12~18%, Lv.4 1%. 칼날 1개 시작안은 Lv.1 스킬의 51%가 통째로 빗나가 제외했고, 3·0 / 3·1 / 5·1 / 5·2안은 Lv.4가 Lv.3보다 적게 맞혀 제외했다.

## D03. 칼날 피해량
- **Chosen**: 칼날 1개가 대상 1마리에 주는 피해는 평타 GREAT 한 발과 같은 1.0 / 1.35 / 1.75 / 2.2, 보스에게는 2 / 2.5 / 3 / 3.5.
- **Rationale**: (사용자 선택) "칼날 하나는 평타 한 발"로 설명하기 쉽고 Lv.4에서 처치 수가 1.4~1.6마리로 늘어난다. 더 강한 안은 Lv.4에서 병맥주를 뺀 전부가 칼날 1개에 잡혀 화면 정리에 가까워져 제외했다.

## D04. 칼날이 포탄도 벤다
- **Chosen**: 칼날 경로의 한맥·보스 포탄을 없애고 평타 요격과 같은 보상을 준다(PERFECT + 처치 보너스, 피버 포함). 포탄을 베어도 관통 수는 줄지 않는다.
- **Rationale**: (사용자 선택) 깎이는 체력의 약 3분의 1이 포탄인데 세 스킬 모두 포탄에 영향이 없었다. 생존 효과는 단정할 수 없고(클리어율 85% → 89%로 오차 안, 포탄 손실은 일반 1.14 → 0.78이나 무적 1.12 → 1.28), 가치는 포격 때 스킬을 쓸 이유가 생긴다는 데 있다. 점수 영향은 계산상 약 1% 이내.

## D05. 칼날 모양과 높이
- **Chosen**: 세로로 세운 초승달 칼날. 바닥 근처부터 약 1.9m까지 덮고, 반투명으로 카메라보다 조금 앞에서 출발한다. 높이 판정은 넣지 않는다.
- **Rationale**: (사용자 선택) 지상 몬스터 0.55m, 보스 중심 1.15m, 카스 라이트·포탄 1.45m가 모두 칼날 안에 들어와 높이 판정은 항상 통과한다. 낮춰서 실제로 빗나가게 하면 조준 없는 스킬이라 플레이어가 대응할 수 없는 빗나감만 늘어난다. 시야 가림은 추정이므로 구현 후 화면에서 확인한다.

## D06. 맞는 순간 판정과 연출
- **Chosen**: 피해는 시전 순간이 아니라 칼날이 닿는 순간에 들어간다. 평타의 찌그러짐·파편·타격음·처치 연출을 재사용하고, 몬스터 실제 높이에 사선 베인 자국을 0.2초 띄운다. 화면 흔들림은 넣지 않는다. 여러 마리를 맞힐 때 타격음이 몰리지 않게 재생 수를 제한한다.
- **Rationale**: (사용자 선택: 연출 범위, 코드 기반 확정: 나머지) 맞는 느낌은 높이 규칙보다 닿는 순간과 보이는 위치가 맞을 때 생긴다. 현재 스킬 경로는 `playShotFx`를 부르지 않아 타격 연출이 없고, 스킬로 죽은 몬스터는 터지지 않고 사라진다. 타격음 중복 제한 장치는 지금 없다.

## D07. 개틀링 스킬을 밀어내기 전용으로
- **Chosen**: 밀기를 Lv.1~4 3 / 3.5 / 4 / 5m로 키우고, 둔화(30~50%, 2~3초)는 유지한다. 피해는 절반인 0.2 / 0.3 / 0.4 / 0.5, 보스에게는 2 / 2.5 / 3 / 3.5로 낮춘다. 부채꼴 판정 제한(`skillArcDeg`)을 없애고 레벨과 무관하게 필드 전체를 민다. 파도 앞면이 닿는 순간 피해와 밀기가 들어가고, 몬스터는 순간이동이 아니라 뒤로 미끄러진다. 평타의 타격 연출을 재사용한다. 이름은 "거품 해일"로 줄인다.
- **Rationale**: (사용자 선택) "거품은 밀기용이지 데미지용이 아니다". 카드 3장(1.3배)을 받아도 체력 1인 몬스터를 한 번에 못 잡고, 처치는 스킬 1회당 0.2~0.35마리로 마무리 수준이다. 멀리서 1m는 잘 안 보여 3~5m로 키웠다. 대가로 밀린 몬스터를 다시 잡느라 클리어가 느려져 점수가 약간 내려간다. 부채꼴은 Lv.1(90도)에서도 필드의 99%에 닿아 레벨업 효과가 거의 없었다.

## D08. 거품 모양과 레벨 성장
- **Chosen**: 작은 거품을 촤악 뿌려 파도처럼 쓸고 가게 하고, 화면 양옆 끝과 필드 끝까지 닿게 속도와 수명을 조정한다. 레벨업하면 거품 수가 늘어난다(초기값 Lv.1~4 120 / 160 / 210 / 280개, 화면을 보고 조정). 거품 수는 보이는 부분만 바꾸며 실제 세기는 D07의 수치가 맡는다. 인스턴싱(같은 모양을 한 번에 그리는 방식)으로 그린다.
- **Rationale**: (사용자 선택: 모양과 거품 수 성장, 코드 기반 확정: 렌더링과 초기값) 지금은 반지름 0.15~0.29m 거품 50개를 시전마다 메시로 따로 만들어, 수를 늘리면 프레임 비용이 커진다. 지금 수명과 속도로는 14~21m까지만 닿는다.

## D09. 밀어내기 끌어당김 버그를 공용 함수로 수정
- **Chosen**: 밀어내기 함수 하나로 합쳐 개틀링 스킬(`BeerCrusherEngine.ts:2161`)과 샷건 평타(`:1959`)를 함께 고친다. 새 거리 = `min(STAGE_CONSTANTS.SPAWN_RADIUS_M, 현재 거리 + 밀기)`로, 대상이 절대 앞으로 오지 않게 한다. 뚫어뻥 스킬은 바꾸지 않는다.
- **Rationale**: (사용자 선택) 현재 `min(16, r + 밀기)`라서 16m 밖 몬스터가 16m로 끌려온다(24m면 8m). 개틀링은 맞은 몬스터의 23~24%가 평균 4~5m 끌려와 평균 이동 거리가 -0.32~+0.01m였다. 샷건 평타는 Lv.2 이상에서 판당 약 29회, 평균 5.6m(멀리 있는 몬스터도 자주 맞히는 봇 기준). 샷건 수정의 밸런스 영향은 오차 안이다. 기존 테스트는 16m 안쪽만 확인해 이 버그를 못 잡았으므로 16m 밖 거리를 테스트에 넣는다.

## D10. 랭킹과 기준 시간
- **Chosen**: `RANKING_RULESET_VERSION`은 v4로 유지하고, v5 여부는 사람이 직접 플레이한 뒤 한 번에 정한다. 웨이브 기준 시간 `parTimeSec`는 변경 후 `measure-wave-times.ts`로 다시 재서 반영한다.
- **Rationale**: (사용자 선택: 랭킹, 코드 기반 확정: 기준 시간) 점수 변화가 약 1~3% 수준이라 규칙상 필수는 아니고, 플레이 뒤 재조정하면 초기화가 두 번 될 수 있다. 버전을 올리면 되돌릴 수 없으므로 직전에 사용자에게 다시 확인한다.

## D11. 기존 규칙을 이어받는 세부 동작
- **Chosen**:
  - 칼날·거품은 올린 오비 방패를 뚫는다. 대왕 쉴드에는 피해를 못 주며, 그 타격도 칼날의 관통 수를 쓴다.
  - 아이템, 황금 캔, 카드, 착지 전 부하는 맞히지 않는다.
  - 스킬 처치 보상은 지금처럼 PERFECT + 처치 보너스다. 정밀도 보너스의 발사 수에는 넣지 않는다.
  - 카드 선택 중에는 시전이 막히고 날아가는 칼날·거품도 게임 시계와 함께 멈춘다.
  - 칼날·거품 상태는 엔진이 소유하고 매 프레임 전진시키며, 화면은 그 상태를 그린다.
- **Rationale**: (코드 기반 확정) `triggerWeaponSkill`의 대상 필터, `isShielded` 처리, `freezeTimers`, 가이드의 "스킬은 방패를 뚫는다" 문구를 그대로 잇는다. 판정을 화면 쪽에 두면 시뮬레이션과 테스트로 검증할 수 없다.

## D12. 수치 위치와 초기값, 이름
- **Chosen**:
  - 칼날 수, 관통, 칼날·거품 피해, 밀기, 거품 수는 `src/shared/gameTuning.ts`에 두고 `applyWeaponTuning`이 무기 표에 덮어쓴다.
  - 칼날 폭은 좌우 0.7m이고 맞는 조건은 `횡거리 ≤ 0.7 + hitRadiusM`이다(시뮬레이션 값). 화면에 보이는 폭도 이에 맞춘다.
  - 칼날 속도 초기값은 40m/s(24m까지 약 0.6초)이고, 화면을 보고 조정한다.
  - 리볼버 스킬 이름은 "오프너 참격"으로 바꾼다. 불릿 타임이 없어지므로 무기 설명, `GuideModal`, `docs/`, README, 테스트 문구를 맞추고 오프너 부메랑 스크린샷(`screen-18`)을 새로 찍는다.
- **Rationale**: (코드 기반 확정, 이름과 속도는 기본값) 프로젝트 규칙상 난이도 수치는 `gameTuning.ts`에 모은다. 둔화 제거와 이름은 사용자 답변에서 이어받은 기본값이며 인터뷰 중 이의가 없었다.

## D13. 리볼버 평타 관통은 범위를 두고 보이게 한다
- **Chosen**: 관통 범위 ±0.16rad와 관통 수·피해율은 유지한다. 뒤쪽 몬스터에도 평타와 같은 번쩍임, 파편, 소리, 처치 연출을 넣는다.
- **Rationale**: (사용자 선택) 엔진이 만드는 `hitTargets`를 화면 쪽이 읽지 않아, 관통이 터져도 보이지 않고 관통으로 죽은 몬스터는 그냥 사라진다. 두 마리 이상 맞은 발은 조준이 흔들리는 봇 11~14%, 정확한 봇 3.7%다. 범위를 넓히면 좌우 3.3m 이상 떨어진 몬스터까지 맞아 일직선처럼 안 보이고, 튕김은 판당 60마리 안팎을 더 잡아 무기 성격이 바뀐다.

## D14. 보스는 기절·둔화에 면역
- **Chosen**: 스킬의 기절·둔화와 샷건 Lv.4 평타의 둔화가 보스에게 걸리지 않는다. 뚫어뻥 부착과 파란 표시도 끈다. 스킬 피해는 그대로 들어가고, 보스에게 날아간 뚫어뻥은 박히지 않고 맞고 튕긴다. 얼음 아이템은 스킬이 아니어서 바꾸지 않는다.
- **Rationale**: (사용자 선택) 지금 보스는 기절·둔화 표시가 뜨지만 이동, 소환, 포격은 그대로여서 표시와 실제가 다르다(걸어오는 16m~10m 구간의 속도만 영향을 받는다). 타이머를 늦추는 안은 샷건 89% → 93%, 개틀링 97% → 87%로 방향이 엇갈려 효과를 확인할 수 없었다.

## D15. 샷건 `spreadRad`를 지운다
- **Chosen**: 무기 표의 값 12곳, `src/shared/types.ts`의 필드, 가이드 표의 "탄착군 확산" 칸을 없앤다. 게임 동작은 바뀌지 않는다.
- **Rationale**: (사용자 선택) 코드 어디에서도 읽지 않는 값이다. 샷건 피해는 `탄환 수 × 탄환당 피해`로 한 마리에게 한 번에 들어가고, 넓게 맞는 느낌은 판정 범위 1.40배에서 나온다. 진짜 산탄 구현은 재조정이 커서 제외했다.

## D16. 공격력 강화를 세 스킬 피해에 모두 적용
- **Chosen**: 칼날, 뚫어뻥, 거품의 일반·보스 피해에 `getDamageBonusMultiplier()`를 곱한다. 카드 3장 +30%와 Lv.4 재강화 +15%가 모두 포함된다. 카드 설명은 "사격·스킬 피해 +10%"로 고친다.
- **Rationale**: (사용자 선택) 규칙이 가장 단순하고 "칼날 하나는 평타 한 발"이 카드를 받아도 유지된다. 역할이 흐려질 위험은 거품 피해를 낮춰(D07) 막았다.

## D17. 샷건 넉백은 유지하고 설명만 고친다
- **Chosen**: 밀기 수치 0 / 0.3 / 0.3 / 0.4m는 그대로 둔다. "다중 산탄 탄착군과 강력한 근접 넉백" 같은 설명을 "넓은 명중 범위와 한 발에 몰아넣는 강한 화력"처럼 실제에 맞게 고친다(`constants.ts`, `docs/무기_및_스킬_가이드.md`).
- **Rationale**: (사용자 선택) 넉백에는 거리 조건이 없어 "근접"이 사실과 다르고, 0.3m는 필굿 기준 약 0.1초로 강력하지 않다. 샷건이 괜찮다는 사용자 판단에 따라 동작은 바꾸지 않는다.

## D18. 직접 플레이는 개편 후 한 번에
- **Chosen**: 이번 개편을 먼저 끝낸다. 기존 체크리스트 `playtest-2026-11-05-skill-guard-ammo.md`에 칼날, 거품, 관통 표시, 보스 면역 항목을 더해 한 번만 플레이한다. 사용자는 체크리스트를 직접 채우지 않고 채팅으로 느낌을 말해도 된다. 에이전트는 들은 내용을 기록하되 대신 통과로 판단하지 않는다. 새 계획이 `current.md` 포인터를 가져가고 기존 작업은 일시 중지 목록으로 옮긴다.
