# Decisions: 무피해 웨이브 보너스 상자

- Date: 2026-11-06
- Status: Confirmed
- 선행: `2026-11-06-boss-hp-and-bottle-speed` 계획을 먼저 구현·플레이한 뒤 진행한다. 두 기능이 같은 엔진·결과 화면 파일을 건드린다.

## D01. 상자를 받는 조건
- **Chosen**: 7웨이브 보스를 잡은 뒤, **피해를 한 번도 입지 않은 웨이브의 수**만큼 상자를 열 수 있다. 무피해 웨이브가 0개면 상자 단계 없이 바로 결과 화면(`VICTORY`)으로 간다.
- **Rationale**: "체력이 닳지 않고도 깰 수 있다"는 피드백에 대응하되, 한 번도 안 맞은 플레이에 보상을 주는 방향이다. 판 전체 무피해 하나가 아니라 웨이브별로 세어 부분적으로 잘한 플레이도 보상한다.

## D02. 웨이브별 피해 기록
- **Chosen**: 웨이브가 끝날 때 그 웨이브 동안 피해가 없었는지를 `waveClears` 항목에 함께 저장한다. 웨이브 시작 시점의 `damageTaken`을 기억해 두고 클리어 시점과 비교한다. 3·5·7웨이브는 보스전까지 한 웨이브로 센다.
- **Rationale**: 지금 `damageTaken`은 판 전체 합계 하나뿐이다(코드를 읽고 자동 확정).

## D03. 상자 결과 (뽑기)
- **Chosen**: 한 상자는 아래 확률로 점수가 나온다. "한 번 더"는 넣지 않는다. 수치는 `GAME_TUNING`에 모아 조정한다.

  | 결과 | 확률 |
  | :--- | :--- |
  | 꽝 (0점) | 10% |
  | +200 | 25% |
  | +500 | 25% |
  | +1,000 | 20% |
  | +2,000 | 12% |
  | +3,000 | 6% |
  | 대박 +10,000 | 2% |
- **Rationale**: 점수대를 여러 단계로 두고 대박은 아주 낮게 했다. 한 상자 기대값은 약 1,000점이고, 무피해 7개를 모두 열어도 평균 약 7,000점으로 정밀도 보너스 최대치(12,000점) 아래라 랭킹을 뒤엎지 않는다. 확률은 플레이해 보고 조정한다.

## D04. 상자 배치와 열기 방식
- **Chosen**: 상자를 20개 깔고(`GAME_TUNING`의 개수로 조정), 총으로 쏴서 연다. 무피해 웨이브 수만큼만 열 수 있고 남은 횟수를 화면에 표시한다. 횟수를 다 쓰면 결과 화면으로 넘어간다. 20개는 여러 줄로 작게 배치한다.
- **Rationale**: 기존 카드 선택(`Shoot-to-Select`)과 같은 사격 방식이라 조작이 자연스럽다. 12개로는 작다는 의견에 따라 20개로 늘렸다. 상세 배치는 계획 단계에서 정한다.

## D05. 게임 단계와 점수 합산
- **Chosen**: 7웨이브 보스 처치 후 `VICTORY` 전에 상자 단계(예: `BONUS_BOX`)를 둔다. 상자 점수는 정밀도·레벨 보너스처럼 `addBonusScore`로 더하고, 결과 화면 점수 내역에 "무피해 상자 보너스" 줄을 추가한다.
- **Rationale**: 지금 `declareVictory()`가 보스 처치 직후 바로 `VICTORY`로 바꾸고 보너스를 더한다. 그 사이에 단계를 끼워야 한다(코드를 읽고 자동 확정).

## D06. 랭킹 규칙 버전
- **Chosen**: 이번 보스 계획은 `RANKING_RULESET_VERSION = 5`로 두고, **상자 기능의 마지막 Task에서 한 번만 6으로 올린다.**
- **Rationale**: 보스 난이도·기준 시간 변경과 상자 점수 추가가 같은 점수 체계를 흔든다. 랭킹 초기화를 한 번으로 끝내고, 보스 난이도를 플레이한 뒤에 결정한다. 올리면 서버가 기존 `players.json`을 백업한 뒤 점수만 초기화한다.

## D07. 튜토리얼·연출 (자동 확정)
- **Chosen**: 튜토리얼은 바꾸지 않고 인게임 가이드(`GuideModal.tsx`)와 문서에만 설명을 추가한다. 연출은 기존 폭발·점수 표시 효과를 재사용하고, 새 효과음·모델은 만들지 않는다.
- **Rationale**: 튜토리얼 흐름(3단계)은 기본 조작 학습용이라 보너스 규칙을 넣을 자리가 아니다. 새 에셋을 만들면 범위가 커진다. 필요하면 나중에 확장한다.
