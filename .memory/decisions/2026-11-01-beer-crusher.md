# Decisions: 비어 크러셔 (Beer Crusher) 요구사항 구체화 및 상세설계

- Date: 2026-11-01
- Status: Confirmed

## D01. 프론트엔드·3D 렌더링·실시간 통신 기술 스택
- **Chosen**: React + Three.js + TypeScript + Node.js WebSocket (Vite 기반 단일 프로젝트 통합 구성)
- **Rationale**: 대기(QR 페어링·랭킹), 로그인(닉네임 등록), 영점 안내, 카운트다운, 인게임 오버레이 HUD, 연결 끊김 일시정지, 결과 화면 및 스마트폰 컨트롤러의 화면 전환은 React 컴포넌트로 선언적으로 관리하고, 60fps 3D 렌더링·물리/판정 루프는 순수 Three.js(`THREE.WebGLRenderer`)로 분리해 성능 저하 없이 관리한다.

## D02. 적(타겟) 라인업 구체화 — OB맥주 캔 4종 + 생맥주 유리잔 + 업소용 생맥주 냉각기 보스 (총 6종)
- **Chosen**: 기존 캔 4종(필굿·카스 라이트·오비라거·한맥) 유지 + 신규 중형 적 '생맥주 유리잔(500ml 크리스탈 머그, 체력 3)' 추가 + 웨이브 3 보스를 '업소용 OB 생맥주 냉각기 디스펜서(체력 30)'로 업그레이드
- **Rationale**: 실제 OB맥주 주류 매장의 상징적 요소인 '거품 가득한 투명 생맥주 유리잔'과 '황금 추출 코크(탭 레버)가 달린 업소용 생맥주 냉각기'를 직접 겨누어 쏘아 부수는 타겟으로 편성해 시각적 다양성과 타격 쾌감을 극대화한다.

## D03. 실제 OB맥주 제품 외형(3D 용기·라벨) 및 사운드 에셋 구현 방식
- **Chosen**: 정밀 3D 프로시저럴 PBR 모델링(금속 광택·유리 투명 굴절·거품 구체 조합) + 고해상도 Canvas 브랜드 라벨 생성기 + 실제 제품 사진(`public/textures/`) 교체 슬롯 지원 + Web Audio API 합성 사운드
- **Rationale**: 외부 에셋 파일이 없는 초기 상태에서도 즉시 실제 제품처럼 보이도록 알루미늄 캔의 네킹(Necking) 곡선·따개, 투명 유리 머그잔과 내부 황금빛 맥주 액체·거품, 업소용 냉각기 및 브랜드 시그니처 라벨을 코드로 정밀 렌더링하며, 추후 실사 이미지나 `.glb`/오디오 파일을 넣으면 즉시 교체되도록 설계한다.

## D04. 3D 스테이지 배경 공간 및 1인칭 발사대 콘셉트
- **Chosen**: 시안 1 — '오비맥주 브루어리 & 네온 펍(Pub) 홀 3D' (1.8m 앞 원목·황동 바 카운터 방어선 + 양옆 구리 맥주 숙성 탱크 + 브랜드 네온사인 + 바닥 10m/20m/28m 거리 눈금) + 우하단 1인칭 '생맥주 디스펜서 탭건'
- **Rationale**: 따뜻한 다크 우드/앰버 조명의 브루어리 펍 홀이 타겟(캔·유리잔·냉각기) 색상 및 황금빛 맥주 물보라·하얀 거품 파티클과의 시각적 대비(시인성)가 가장 뛰어나고 브랜드 공간 몰입감이 높다.

## D05. PC 화면 전체 레이아웃 및 단독 플레이(디버그) 지원
- **Chosen**: 16:9 풀스크린 3D 캔버스(`100vw × 100vh`) + 네 모서리 반투명 아케이드 오버레이 HUD + QR 대기 모달 내 `[PC 마우스/키보드로 즉시 시작]` 겸용 제공
- **Rationale**: 3D 스테이지가 화면 전체를 채워 아케이드 슈팅의 공간감을 살리고, HUD를 네 모서리에 배치해 중앙 조준 시야를 확보한다. 스마트폰 미연결 시에도 마우스/키보드로 즉시 플레이 및 테스트가 가능하도록 한다.

## D06. `PERFECT` 정밀 판정 등급 추가 및 피버 완충 시 감소 방지(Lock) 규칙
- **Chosen**:
  - **판정 3단계**: `PERFECT`(오차율 `0.15 이하`, `150점`, 피버 게이지 `+30`) / `GREAT`(오차율 `0.15 초과 ~ 0.45 이하`, `100점`, 게이지 `+20`) / `GOOD`(오차율 `0.45 초과 ~ 1.00 이하`, `50점`, 게이지 `+10`)
  - **피버 100% 완충 Lock**: 게이지가 100 미만일 때는 빗나가면 `-5` 감소하지만, **게이지가 100까지 다 차면(`gauge === 100`) 빗나가도 절대 내려가지 않고 100으로 유지**됨 (콤보만 0으로 초기화).
- **Rationale**: 정중앙 초정밀 조준에 대한 보상(`PERFECT`)을 강화해 스냅 사격의 손맛을 높이고, 어렵게 100%까지 모은 피버 게이지가 발동 직전 빗나감 한 발 때문에 95%로 깎여 피버가 불발되는 불쾌한 경험을 방지한다.

## D07. 부채꼴(시점 모양) 몬스터 방사형 스폰 및 카메라 고정
- **Chosen**: 배경 화면(카메라 시점)은 정면에 고정하고, 눈에 보이는 **수평 부채꼴 시야각 전체(반경 `R = 28m` 원호, 왼쪽 끝 `−36°` ~ 가운데 `0°` ~ 오른쪽 끝 `+36°`)**에서 몬스터가 골고루 스폰되어 플레이어(부채꼴 꼭짓점)를 향해 사방에서 방사형으로 달려오도록 구성
- **Rationale**: 기존 목업처럼 정면 좁은 구간(`±7m`)에서만 일자로 나오면 미니맵 부채꼴의 양옆이 비어 단조로우므로, 화면을 흔들지 않으면서도 눈에 보이는 부채꼴 시야 전체에서 적들이 입체적으로 조여 들어오게 하여 아케이드 슈팅의 박진감을 높인다.

## D08. QR 연결 시 폰 고유번호(`deviceId`) 기반 로그인·닉네임 등록 및 TOP 5 랭킹
- **Chosen**:
  - QR 스캔 접속 시 스마트폰 고유 식별자(`deviceId`: 영구 UUID + 기기 핑거프린트)를 추출해 서버 로컬 DB(`data/players.json` 또는 SQLite)에서 조회
  - **신규 회원**: 폰 화면에 `닉네임 입력(2~10자)` 화면을 띄워 등록 후 로그인 완료
  - **기존 회원**: 닉네임 입력 없이 즉시 자동 로그인하여 기존 닉네임과 최고 기록 불러오기 (닉네임 변경 보조 버튼 제공)
  - **PC 화면 연동**: 접속된 플레이어 닉네임/최고 기록 표시 및 대기·결과 화면에 **TOP 5 명예의 전당 랭킹 보드** 노출
- **Rationale**: 별도 아이디/비밀번호 입력 없이도 QR 스캔만으로 폰을 식별해 재방문 유저는 즉시 진입시키고, 플레이어별 기록 갱신과 현장 TOP 5 랭킹 경쟁 요소를 제공한다.

## D09. 권총 파지 자세(폰 윗부분=모니터, 화면=좌측) 센서 축 인식 및 85:15 통합 터치 컨트롤러
- **Chosen**:
  - **파지 자세 및 센서 인식 축**:
    - 휴대폰 **윗부분(상단 베젤, `+Y축`)**이 모니터 정면(총구 방향)을 향하고, **액정 화면(`+Z축`)**은 **좌측(왼쪽)**을 바라보며, **오른쪽 긴 테두리(`+X축`)**가 **천장(위쪽)**을 향하는 권총 그립 기준
    - **조준(Yaw/Pitch)**: 휴대폰 `+Y축(총구 벡터)`의 3D 회전 행렬/쿼터니언을 이용해 영점 자세 대비 좌우 방위각(`±35°`)과 상하 고도각(`±20°`)을 계산
    - **단발 스냅**: 손목을 위로 탁 쳐올릴 때 천장을 향한 **오른쪽 긴 테두리 방향(`+X축` 가속도 ≥ 12 m/s²) 및 상향 회전 각속도**로 단발 격발 인식
  - **통합 터치 조작 및 자동 재장전**:
    - **재장전**: 수동 재장전을 제거하고 **10발 소진 시 1.2초 자동 재장전**만 사용
    - **폰 화면 85% (몸쪽~중앙 통합 액션 패드)**: 폰 화면을 보지 않고 엄지나 반대손으로 같은 영역을 터치하여 조작 — **꾸욱 누르기(0.25초 이상 홀드) = 연사**, **두 번 터치(0.3초 이내 더블탭) = 피버(FEVER) 발동**
    - **폰 화면 15% (모니터 쪽 앞단)**: **`[🎯 영점 재설정]`** 전용 버튼 배치 (가로 파지 시선에 맞춰 텍스트 90° 회전 표시)
- **Rationale**: 플레이어가 모니터만 보면서 휴대폰을 권총처럼 쥐고 쏘기 때문에, 눈으로 폰 화면의 여러 버튼을 구분할 필요 없이 하나의 넓은 터치 영역에서 홀드(연사)와 더블탭(피버)을 모두 수행하고 장전은 자동화하여 조작 직관성을 극대화한다.
