# Decisions: Weapon-Specific Crosshairs and Hit-Detection Alignment

- Date: 2026-11-03
- Status: Confirmed
- Feature: 무기별 조준경 UI 차별화 및 조준경-히트 판정 1:1 동기화 (미스 판정 완화)

## D01. 무기별 조준경 UI 비주얼 아키텍처 및 무기 레벨 연동
- **Chosen**:
  1. `CrosshairOverlay`에 `weaponKind: WeaponKind`와 `weaponLevel: WeaponLevel`을 prop으로 전달받아 무기 아키타입별로 완전히 다른 3종 전용 HUD 비주얼을 렌더링한다.
     - 🪠 **맥주관 뚫어뻥 샷건 (`shotgun`)**:
       - 120px 대형 원형 펠릿 탄착군 링 (`diameter: 120px`, `radius: 60px`) + 8방향 펠릿 확산 도트 + 옥타곤 브래킷.
       - 메인 컬러: 앰버 오렌지 (`#f59e0b` / `#fbbf24`), 발사 시 1.3배 팽창 킥 애니메이션.
       - 레벨별 시각 진화: Lv.1 기본 링 ➔ Lv.2 4방향 보조 눈금 ➔ Lv.3 8방향 펠릿 분산 도트 ➔ Lv.4 폭풍 소용돌이 네온 회전.
     - 🍾 **황금 병따개 리볼버 (`revolver`)**:
       - 76px 초정밀 스나이퍼 십자선 (`hairline: 1px`, `length: 76px`) + 중앙 3px 핀포인트 닷 + 상하 수직 관통 가이드라인 (`pierce ray guide`).
       - 메인 컬러: 럭셔리 골드 (`#eab308` / `#fef08a`), 사격 시 십자선이 순간적으로 좁혀졌다 복귀하는 스나이퍼 리코일.
       - 레벨별 시각 진화: Lv.1 기본 십자선 ➔ Lv.2 헤드샷 마커 ➔ Lv.3 수직 관통 눈금선 ➔ Lv.4 황금 광선 펄스.
     - 🍺 **탄산 탭 개틀링 (`gatling`)**:
       - 88px 3각 톱니 터빈 회전 레티클 + 중앙 44px 스프레드 서클 + 3방향 탄산 노즐 핀.
       - 메인 컬러: 시안/일렉트릭 블루 (`#06b6d4` / `#38bdf8`), 사격 시 터빈이 고속 회전하는 스핀 애니메이션.
       - 레벨별 시각 진화: Lv.1 기본 톱니 ➔ Lv.2 3각 노즐 핀 ➔ Lv.3 RPM 가속 회전 ➔ Lv.4 일렉트릭 과충전 아크.
- **Rationale**: 기존에 모든 무기가 동일한 88px 네모 브래킷을 공유하여 무기를 변경해도 조준 감각에 차이가 없었으며, 특히 샷건이나 개틀링처럼 탄착군이 넓은 무기의 성격이 시각적으로 전달되지 못했던 문제를 해결한다.

## D02. 조준경 가시 범위와 엔진 피격(Hit) 판정 1:1 동기화
- **Chosen**:
  1. 유저 선택 **1번** 확정: 조준경에 보이는 범위 그대로 히트 판정이 나도록 완전히 일치시킨다.
  2. `BeerCrusherEngine.ts`의 `shootAt` 판정 시 무기별 유효 판정 배율(`weaponHitToleranceMult`)을 적용한다:
     - 🪠 **샷건**: `apparentHitRadius * 1.55` (120px 대형 조준경 링 안에 타겟이 조금이라도 걸치면 100% 유효타 보장).
     - 🍾 **리볼버**: 수평 오차는 `apparentHitRadius * 0.95`로 날카롭게 유지하되, 수직 관통 레이 특성을 반영하여 수직 허용 오차 계수를 `dy * 0.70` (기존 0.85 대비 1.2배 완화)로 보정하여 관통 샷의 쾌감을 보장.
     - 🍺 **개틀링**: `apparentHitRadius * 1.25` (88px 스프레드 서클 내 연사 타격 보정).
  3. `evaluateHitJudgment` 등급 판정 시에도 `apparentHitRadius`가 무기 판정 배율을 반영하여, 조준경 내에 정상 조준된 사격이 부당하게 `MISS` 처리되어 콤보와 피버가 끊기는 치명적인 억울함을 완벽히 제거한다.
- **Rationale**: 몬스터가 조준경 원 안에 명확히 들어와 있음에도 바늘구멍 같은 단일 점(Point) 판정으로 인해 MISS가 발생하고 콤보가 박살나던 문제를 원천 해결하고, 무기별 개성과 실제 타격 범위가 완벽히 일치하는 직관적인 아케이드 슛 감각을 제공한다.
