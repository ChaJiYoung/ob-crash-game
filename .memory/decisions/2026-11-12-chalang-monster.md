# Decisions: 찰랑 몬스터 (Chalang Submerge Monster)

- Date: 2026-11-12
- Status: Confirmed (D04·D09·D10은 구현 후 테스트로 조정 가능)

## D01. 잠수 중 타격 가능 여부
- **Chosen**: 물속에 있는 동안은 타격 불가. 수면 위에 떠올랐을 때만 맞힐 수 있다.
- **Rationale**: 기존 방패 병(`obi`)처럼 "올라왔을 때 쏘는" 타이밍 규칙을 따르면서도 플레이어가 예측 가능한 공정한 구조가 된다.

## D02. 잠수 시간과 등장 방식
- **Chosen**: 물속 시간은 매번 1.5~3초 사이 무작위. 수면에 올라올 때 화면 안 무작위 위치로 즉시 순간이동한다.
- **Rationale**: 고정 주기(`obi` 방식)와 확실히 다른 리듬을 만들고, 위치 변화로 긴장감을 준다. 거품 해일의 "순간이동 아님" 규칙과는 별개의 몬스터 고유 행동으로 한정한다.

## D03. 등장 위치 제약
- **Chosen**: 화면 안 무작위 위치 중 방어선 바로 앞 구간은 등장 후보에서 제외한다.
- **Rationale**: 등장과 동시에 방어선을 뚫는 억울한 피격을 막고, 플레이어가 반응할 시간을 보장한다.

## D04. 물속 전진 규칙 (잠정)
- **Chosen**: 물속에서는 전진하지 않고, 수면 위에 있을 때만 방어선 쪽으로 전진한다.
- **Rationale**: 잠수 시간이 위협이 아니라 타격 기회 조절로만 작용하게 한다. 사용자 의견 "여기저기 올라오다가"에서 잠정 도출했으므로 테스트 후 확인한다.

## D05. 급발진 트리거
- **Chosen**: 3번 등장하면 급발진하고, 방어선에 닿을 때까지 그 속도를 유지한다(한 번만 발동).
- **Rationale**: 등장 횟수라는 새 트리거를 쓰지만 규칙이 단순해 예측이 쉽다. 기존 `pilgood`의 거리 기반 돌진과 구분된다.

## D06. 체력과 피해 규칙
- **Chosen**: 체력 3. 수면 위 피격 피해는 기존 몬스터와 같은 무기 피해 규칙을 그대로 쓴다(피해 1 고정 아님). 물속에서는 체력이 회복되지 않는다(회복 없음은 가정).
- **Rationale**: 피해를 1로 고정하면 무기 레벨 차이가 사라지므로, 기존 무기 체계와 맞추기 위해 무기 피해를 그대로 적용하기로 사용자가 선택했다. 체력 3은 기존 `bottle`과 같은 수치다.

## D07. 급발진 속도
- **Chosen**: 평소 속도의 3배.
- **Rationale**: 확실히 위협적으로 느껴지는 배율이다. 방어선 도달 시간이 짧아지므로 밸런스 시뮬레이션으로 재조정한다.

## D08. 캐릭터 에셋 출처 (수정: 2026-11-12 사용자 변경)
- **Chosen**: 제공 이미지(검은 덩어리 위에 찰랑 병)의 투명 배경 PNG를 카스 누끼 빌보드와 같은 방식으로 쓴다(`public/textures/chalang_cutout.png`). 3D 직접 제작은 취소.
- **Rationale**: 직접 만든 3D 모델이 원본과 달라 "징그럽다"는 피드백이 나왔다. 원본 이미지를 그대로 쓰면 원본과 일치한다. 원본 사용 권한은 사용자가 확인해야 한다(오비맥주 공식 누끼는 찾지 못함).

## D09. 등장 웨이브 (보류: 테스트 후 결정)
- **Chosen**: 구현 후 샌드박스에서 테스트하여 결정한다. 임시 값은 웨이브 3.
- **Rationale**: 웨이브 배치는 실제 플레이 난이도 곡선에 따라 달라지므로 구현 후 측정이 더 정확하다.

## D10. 물속 회복 없음 (가정 확인 필요)
- **Chosen**: 물속에서 체력이 회복되지 않는다.
- **Rationale**: D06 선택에 따라 추가한 가정이다. 회복 규칙이 필요하면 구현 전에 변경한다.
