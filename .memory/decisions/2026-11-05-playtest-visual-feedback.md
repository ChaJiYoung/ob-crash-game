# Decisions: 플레이 소감 반영 (장전 링, 스프링 똥, 피격 효과, 보스 경고, 냉각기 디자인)

- Date: 2026-11-05
- Status: Confirmed

시안 이미지는 합성·간이 렌더링이며 실제 게임 화면이 아니다. 수치는 구현 때 눈으로 조정할 수 있는 시작값이다.

## D01. 장전 게이지 링 강화 + 장전 중 조준점 흐림
- **Chosen**: 링 두께 4px → 8px, 검은 외곽선 추가, 바탕 링 진하게. 장전 중에는 조준점을 반투명(시작값 45%)하게 한다. 색은 HUD의 장전 문구와 같은 `#f87171`을 유지한다. 피버 중에는 지금처럼 링이 없고 조준점도 흐려지지 않는다.
- **Rationale**: (사용자 선택: 1번) 링이 얇고, 샷건에서는 조준점 모서리와 겹쳐 잘 안 보인다는 소감. 색 유지는 코드 기반 기본값이다.
- **영향**: `src/pc/components/CrosshairOverlay.tsx`의 `getReloadRingSpec`, `ReloadRing`, 조준점 렌더링.

## D02. 똥은 바닥에 붙어 스프링처럼 늘었다 줄었다 하며 다가온다
- **Chosen**: 공중에 뜨지 않고 바닥에 붙은 채 위아래로 늘고 줄며(부피감을 유지하도록 납작할 때 옆으로 퍼짐) 미끄러져 온다. 이동 속도 3.2 m/s, 요격 규칙, 발사 간격은 그대로 둔다.
- **Rationale**: (사용자 선택: 3번) 둥둥 떠다니는 모습이 이상하다는 소감. 떠오르지 않으므로 보이는 곳과 판정 위치가 가장 잘 맞는다.
- **코드 기반 확정**:
  - `spawnMonsterProjectile`의 `customBaseY: 1.45`를 바닥 높이(모델 아래 단이 바닥에 닿는 값, 시작값 약 0.28)로 낮추고 `customNormY: 0.1`을 없앤다. `customNormY`가 남으면 판정이 화면 높이에 고정되어 모델과 어긋난다.
  - `GameCanvas3D.tsx` 포탄 분기의 회전(`rotation.y`, `rotation.z`)을 없애고 플레이어를 보게 해 눈이 항상 보이게 한다. 이는 이전 결정(boss-summon-shell-and-speed D08)의 "뱅글뱅글 굴러온다"를 대체한다.
  - 바닥에 있다는 것이 보이도록 `createFloorShadowMesh`로 그림자를 추가한다.
  - 발사 사건의 높이(`y: 1.45`)도 새 높이에 맞춘다.
  - 튈 때 소리는 넣지 않는다(동시에 여러 개가 나오면 시끄러움).
- **주의**: 판정 계산이 실제 거리 기준으로 바뀌어, 10m에서 판정 반경이 계산상 약 19% 작아진다(`baseHitRadius`: 카메라 거리 10m → 약 12.3m). 대신 세로 허용치는 넓어진다(`verticalScale` 적용). 시뮬레이터로 전후를 비교하고, 필요하면 `hitRadiusM`(0.95)을 조정한다.
- **영향**: `BeerCrusherEngine.ts`, `GameCanvas3D.tsx`, `TargetModels3D.ts`의 `createProjectileMesh3D`, `tests/poop-shell.test.ts`.

## D03. 피격 효과는 약하게: 빨간 번쩍임과 소리만
- **Chosen**: 체력이 줄 때 화면 가장자리가 빨갛게 번쩍이고(시작값 약 0.4초) 피격음이 난다. 모든 피격에 똑같이 나온다. 화면 흔들림, 폰 진동, 똥 얼룩은 넣지 않는다. 서버와 폰 코드는 고치지 않는다.
- **Rationale**: (사용자 선택: 3번) 맞았다는 것을 알리되 조준을 방해하지 않는다.
- **코드 기반 확정**: `engine.update`가 돌려주는 `breaches`를 신호로 쓴다. 지금은 `GameCanvas3D.tsx`가 이 값을 버리고 있다. 튜토리얼·샌드박스와 아이템은 `breaches`에 들어가지 않으므로 체력이 실제로 줄 때만 나온다. 소리는 `SoundSynthesizer`에 새로 추가하고, 번쩍임은 황금 캔 테두리와 같은 전체 화면 오버레이 방식(`pointerEvents: none`)으로 만든다. 마지막 체력을 잃으면 결과 화면으로 넘어가므로 효과가 짧게 보이거나 가려질 수 있다.

## D04. 보스 경고는 가로 띠 + 빛줄 + 경고음
- **Chosen**: 알약 모양 문구를 화면 가로 전체의 어두운 빨간 띠로 바꾼다. 큰 `WARNING`과 작은 `보스 등장`을 쓰고, 밝은 빛줄이 글자 위를 왼쪽에서 오른쪽으로 반복해서 훑는다. 짧은 경고음을 낸다. 표시 시간 2초와 게임 진행(멈추지 않음)은 그대로다.
- **Rationale**: (사용자 선택: 1번, 시안 확인) 경고 위로 라인이 지나가는 효과를 원한다는 소감. 3안(전체 스캔선)은 조준점과 보스를 가린다.
- **코드 기반 확정**: 띠 위치는 체력·보스 체력바 아래(시안 기준 top 약 21.5%, 높이 약 17%). 처음 시안의 위치는 HUD를 가려 낮췄다. `data-testid="boss-warning-banner"`는 유지한다.
- **7웨이브 겹침(사용자 결정)**: 7웨이브에서 보스 체력바가 늘어 띠와 잠깐 겹칠 수 있다. 사용자는 위치를 따로 조정하지 않고 "잠깐 뜨고 사라지게" 하라고 했다. 띠가 2초 안에 나타났다가 서서히 사라져 없어지게 하고, 끝난 뒤에는 아무것도 남지 않는다. 2초를 더 줄일지는 플레이 뒤 `GAME_TUNING.boss.warningMs`로 조정한다.
- **시안**: `.memory/references/screens/mockup-boss-warning-2026-11-05.png`

## D05. 냉각기 모델을 실제 제품 구조로 다시 만든다
- **Chosen**:
  - 공통: 위쪽 타워를 없애고 실제 업소용 순간냉각기처럼 세로로 긴 몸통 앞면에 탭을 단다. 탭 아래에 그물망 덮인 검정 물받이, 옆면에 통풍구, 앞면에 이름판을 둔다.
  - 소형(냉각기): 은색 스테인리스, 검정 레버 탭 1개, 실제 OB 로고 이름판(D06), 은색 테두리.
  - 대형(대왕): 검정 몸통, 금색 레버 탭 3개, 금색 왕관, 실제 OB 로고 이름판(D06), 금색 테두리. 왕관은 게임 거리에서 보이도록 크게 다듬어도 된다.
- **Rationale**: (사용자 선택: 시안 1안) 소형을 1구로 하고 싶고 대형은 미정이라고 했으며, 소형도 다시 해도 좋다고 했다. 사용자 요청으로 실제 제품을 검색했다. OB 로고가 붙은 제품 사진은 찾지 못해 일반 한국 업소용 제품 사진을 참고했다. 7웨이브에 함께 나올 때 대왕이 가장 잘 구분되는 안이다.
- **코드 기반 확정**:
  - 체력, 판정 범위, `kingScale` 1.5, 이동, 소환, 발사는 바꾸지 않는다. 외형만 바꾼다.
  - `createTargetMesh3D(kind)`에는 역할 정보가 없으므로 소형·대형을 구분할 인자를 추가하고, `GameCanvas3D.tsx`에서 `target.bossRole`을 넘긴다.
  - 소환 때 레버가 젖혀지는 연출을 위해 `bossTapHandles`에 새 레버를 넣는다.
  - `ShaderWarmup.ts`의 예열 목록에 대왕 모델을 추가한다.
  - 도감·가이드의 "듀얼 골드 탭" 등 외형 설명과 도감 스크린샷을 갱신한다.
- **시안**: `.memory/references/screens/mockup-boss-cooler-design-2026-11-05.png`
- **참고한 제품 페이지**: https://m.icepia.co.kr/product/list.html?cate_no=664 , http://samsunplus.com/dispenser

## D06. 이름판에 실제 OB 로고를 쓴다
- **Chosen**: 소형·대형 이름판 모두 위키미디어 공용의 오비맥주 로고(`Oriental_Brewery_Co.,Ltd._logo.jpg`, 334×113, 흰 바탕)를 `public/textures/labels/ob-logo.jpg`로 넣어 쓴다. 파일만 바꾸면 교체되게 한다.
- **Rationale**: (사용자 요청 "실재 로고면 좋겠다") 저장소에 실제 로고 파일이 없고 공식 사이트는 자동 접속이 안 되어, 출처가 `www.obbeer.co.kr`로 표기된 공개 파일을 썼다.
- **한계(사용자에게 보고함)**: 위키미디어 표기는 저작권상 공개 도메인이지만 상표권은 별개다. 2020년 새 CI 이전의 로고이고 해상도도 낮다. 대외 공개 전에 오비맥주 측 승인과 최신 로고 파일을 받아 같은 경로에 교체한다.

## D07. 대왕이 바닥에 파묻히는 문제를 함께 고친다
- **Chosen**: 대왕에 `customBaseY = getTargetBaseY('boss') * kingScale`(1.725)을 준다. 그림자도 바닥에 맞춘다.
- **Rationale**: (코드 기반 확정, 실측) 모델을 가운데 기준으로 1.5배 키워 대왕 아래쪽이 바닥 밑 0.94m까지 내려간다(소형은 0.25m). 새 모델은 물받이가 아래쪽에 있어 그대로면 가려진다. 올리면 판정 중심도 1.5m → 2.075m로 같이 올라가 새 몸통 중심(약 2.17m)에 가까워진다. 판정 크기는 그대로다.

## 범위 밖 (이번 결정에 넣지 않음, 사용자에게 보고함)
- 난이도: 사용자 소감은 "거의 비슷했다"이고 개틀링은 아직 해 보지 않아 뒤에 다시 알려주기로 했다. 값은 고치지 않는다(봇 기준 보통 클리어율은 샷건 15%, 개틀링 45%, 리볼버 82%).
- 이전 계획의 사람 플레이 확인(P04-T03)과 랭킹 v5 여부는 개틀링 플레이 뒤로 미룬다.
- 장전 링과 피격 효과는 PC 화면 기준이며, 폰 컨트롤러 화면은 바꾸지 않는다.
- 상표 사용 확인: D06 참고. 사용자에게 보고한다.
