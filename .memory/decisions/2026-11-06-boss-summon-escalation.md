# Decisions: 보스 소환 점증

- Date: 2026-11-06
- Status: Confirmed

## D01. 체력 구간별 소환을 4·5·6마리로 한다
- **Chosen**: 각 보스의 99% / 66% / 33% 구간에서 4, 5, 6마리를 소환한다(보스당 15마리).
- **Rationale**: (사용자 제안·선택) 6판 전승으로 쉽다는 소감. 보스가 약해질수록 몰려와 막판이 어려워진다. 보통 봇 100판: 샷건 87%, 리볼버 97%, 개틀링 92%(4·4·4는 88 / 100 / 99%).

## D02. 규칙 버전은 v5를 유지한다
- **Chosen**: `RANKING_RULESET_VERSION`을 올리지 않는다.
- **Rationale**: (사용자 선택) 변화가 작아 시작한 지 얼마 안 된 랭킹을 지우지 않는다.

## D03. 기준 시간은 재측정 후 보스 웨이브 값만 반영한다
- **Chosen**: `measure-wave-times.ts`로 재고, 소환이 영향을 주는 3·5·7웨이브 `parTimeSec`만 바꾼다.
- **Rationale**: (코드 기반 확정) 소환 변경은 다른 웨이브에 영향이 없고, 측정 오차로 값이 흔들리는 것을 막는다.
