# Decisions: 플레이 테스트 피드백 (랭킹 표시, 로비 마우스 조준점, 2인 카드 빈도, 조준경 HUD)

- Date: 2026-11-08
- Status: Confirmed

## D01. 랭킹 범위는 그대로
- **Chosen**: 상위 5개 표시, 규칙 버전 필터(`RANKING_RULESET_VERSION`), 2인팟 점수를 개인 랭킹에서 빼는 것(2026-11-07-two-player-coop D05/D22)은 바꾸지 않는다.
- **Rationale**: "전체가 안 보인다"는 착각으로 확인됐다.

## D02. 입력 방식(마우스/모바일)을 기록에 저장
- **Chosen**: 판 기록(`PlayRunStats`)과 랭킹 항목(`RunRankingEntry`, `TeamRankingEntry`의 멤버별)에 입력 방식 `'mouse' | 'mobile'`을 선택 필드로 추가한다. 이 필드가 없는 옛 기록도 유효하고, 화면에는 아이콘 없이 표시한다.
- **Rationale**: 지금은 입력 방식을 어디에도 저장하지 않는다. 선택 필드로 두면 기존 기록과 규칙 버전을 건드리지 않는다.

## D03. 개인 랭킹 표시
- **Chosen**: 각 줄에 입력 방식 아이콘(🖱 / 📱)을 붙인다. 무기는 지금처럼 표시한다.
- **Rationale**: 마우스와 모바일은 조작 난이도가 달라 기록을 볼 때 구분이 필요하다.

## D04. 팀 랭킹 표시
- **Chosen**: 팀 합계와 함께 1P·2P 각자의 점수, 무기, 입력 방식을 보여 준다. 이를 위해 `TeamRankingEntry` 멤버에 `score`, `weaponKind`, `inputKind`를 추가한다.
- **Rationale**: 사용자 요청. 지금은 팀 합계와 닉네임만 보인다.

## D05. 결과 화면(클리어·게임 오버)
- **Chosen**: 결과 화면에도 플레이어별 점수, 무기, 입력 방식을 보여 준다(1인 판은 한 명분).
- **Rationale**: 사용자 요청. 랭킹과 같은 정보를 판 직후에도 확인하게 한다.

## D06. 로비 마우스 조준점
- **Chosen**: 로비에서 마우스 슬롯을 고르면 모바일과 같이 그 플레이어의 십자선을 보여 주고 마우스 커서를 따라가게 한다.
- **Rationale**: 증상은 로비에서 마우스를 고르면 십자선이 안 보이고, 게임에 들어가면 정상인 것이다.

## D07. 2인 판 카드 빈도는 시뮬레이션으로 정한다
- **Chosen**: 엔진만 돌리는 시뮬레이션(테스트 코드 형태)으로 1인 판과 2인 판의 웨이브별 처치 수(병 조각, 소환 졸개 포함)를 측정한다. 그 결과로 2인 판에서 킬 게이지가 차는 횟수가 1인 판과 비슷해지는 `playerCountRules[2].cardKillTargetMult`를 정한다(지금 2, 예상 2.5~3). 처치 수를 세는 규칙과 1인 판 값은 바꾸지 않는다. 시뮬레이션 결과와 고른 숫자는 계획/실행 보고에 남긴다.
- **Rationale**: 2인 판에서는 게이지가 한 번 찰 때 두 사람 모두 카드를 받으므로, 게이지가 차는 횟수가 같으면 한 사람이 받는 카드 수가 1인 판과 같다. 감으로 정하지 않고 측정해서 정한다.

## D07-1. 카드 배율 조정 보류 (D07 수정, 시뮬레이션 후 추가)
- **Chosen**: 지금 `cardKillTargetMult`(2)를 바꾸지 않는다. 카드 선택 기록(D09)이 몇 판 쌓인 뒤 실제 수치를 보고 다시 정한다. 시뮬레이션은 회귀 테스트로 남긴다.
- **Rationale**: 몬스터를 모두 처치하는 봇으로 시드 5개를 돌린 시뮬레이션 결과, 2배에서 2인 판의 웨이브 중간 카드 횟수는 1인 판과 같았다. 4웨이브는 1인 56킬·2.0회, 2인 114킬·2.0회였다. 6웨이브는 1인 57킬·1.8회, 2인 109킬·1.8회였다. 3배로 올리면 2인 판은 1.0회로 절반이 된다. 웨이브 클리어 카드를 더하면 1인·2인 모두 웨이브당 약 3번이라, 체감과 수치가 다르다. 지금 기록에는 카드 9종 중 4종의 스택과 무기 레벨만 있어 실제 판을 확인할 수 없다.

## D09. 카드 선택 기록
- **Chosen**: 판 기록(`PlayRunStats`)에 `cardPicks?: { wave: number; kind: RewardCardKind; midWave: boolean; auto: boolean }[]`를 추가한다. 플레이어별로 고른 순서대로 쌓는다. 옛 기록에는 없다(선택 필드).
- **Rationale**: 1인과 2인의 카드 횟수를 실제 플레이로 비교하려면 필요하다. 입력 방식 저장(D02)과 같은 파일을 건드리므로 P01-T01에 묶는다.

## D08. 조준경 링 게이지
- **Chosen**: 십자선 둘레에 얇은 원호 3개를 둔다. 위쪽은 남은 탄창(장전 중에는 차오름), 왼쪽 아래는 스킬 충전(스택 수는 점으로), 오른쪽 아래는 피버 게이지다. 다 차면 반짝인다. 2인 판에서는 각자 자기 십자선에 자기 상태만 보이고, 화면 아래쪽 개인 패널은 그대로 둔다.
- **Rationale**: 플레이 중에는 아래쪽 패널을 볼 여유가 없다. 링은 시선을 옮기지 않아도 보이고 조준을 덜 가린다.
