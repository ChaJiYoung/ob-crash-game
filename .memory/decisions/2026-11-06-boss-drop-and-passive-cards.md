# Decisions: 보스 부하 드롭 감소와 패시브 카드 표시

- Date: 2026-11-06
- Status: Confirmed

## D01. 보스 부하 드롭률을 20%에서 10%로 낮춘다
- **Chosen**: `boss.summonDropChance` 0.20 → 0.10. 아이템 종류와 일반 몬스터 드롭 4%는 그대로다.
- **Rationale**: (사용자 선택: 1번, 제시한 8~10% 중 상한값은 코드 기반 기본값) 맞아도 보스전 드롭으로 체력이 채워져 잘 죽지 않는다는 소감. 계산상 보스전 회복 아이템이 약 4.5개에서 약 2.3개로 준다.

## D02. 적용 중인 패시브 카드를 무기 칸 옆에 표시한다
- **Chosen**: 왼쪽 아래 무기 칸 오른쪽에 아이콘과 누적 수를 표시한다. 대상은 쌓이는 카드 6종(공격력 강화, 스킬 가속, 피버 연장, 조준 보정, 초고속 장전, 행운의 보급품)이다. 즉시 효과인 레벨업, 수리, 피버 부스터는 제외한다. 없으면 표시하지 않는다.
- **Rationale**: (사용자 선택) 어떤 카드가 적용 중인지 전투 중에 확인한다. 결과 화면 표시는 범위 밖이다.

## 범위 밖
- 받은 피해·회복량·아이템 수 기록은 제안했으나 이번 요청에 포함되지 않았다. 사용자에게 묻는다.
- 규칙 버전은 v5를 유지한다(직전 결정과 같은 방침).
