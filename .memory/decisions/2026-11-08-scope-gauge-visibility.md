# Decisions: 조준경 게이지 가시성

- Date: 2026-11-08
- Status: Confirmed
- Trigger: 사용자 "조준경의 피버·스킬·포탄(탄창) 모양은 좋은데 눈에 잘 안 들어온다. 더 굵게, 다 찼을 때 반짝여 눈에 띄게."

## D01. 굵기 3px → 6px
- **Chosen**: 탄창·스킬·피버 호와 트랙, 장전 채움 호의 `strokeWidth`를 3에서 6으로 올린다. 스킬 스택 점의 반지름은 3에서 4.5로 키운다. 점과 호가 겹치지 않도록 점 궤도 반지름은 `r + 9`에서 `r + 11`로 넓힌다.
- **Rationale**: 사용자가 1번을 선택. 두 배로 굵히면 잘 보이고, 십자선 본체를 가리지 않는다.

## D02. 가득 찼을 때 글로우 펄스
- **Chosen**: `arc.flash`(스킬 가득·피버 준비) 상태에서 자기 색 `drop-shadow` 글로우를 넣고, 굵기 6 ↔ 9px와 밝기를 0.6초 주기로 왕복시킨다. 기존 투명도 0.45 ↔ 1 깜빡임은 없앤다. `prefers-reduced-motion`에서는 애니메이션 없이 굵기 9px와 글로우만 고정으로 둔다.
- **Rationale**: 사용자가 1번을 선택. 흐려졌다 밝아지는 방식은 오히려 덜 보였다.

## D03. 탄 부족 경고 (코드를 읽고 자동 확정)
- **Chosen**: `arc.warn`(탄 20% 미만)도 지금처럼 같은 클래스로 깜빡이지만, 글로우 펄스가 아닌 기존 투명도 깜빡임 클래스(`scope-gauge-warn`)로 분리한다.
- **Rationale**: 경고는 "가득 참"과 의미가 반대다. 같은 반짝임을 쓰면 헷갈린다.
