# Decisions: Screen Edge Aim Deadzone Fix and Floor Defense Line Visualization

- Date: 2026-11-02
- Status: Confirmed

## D01. Screen Edge Aim Deadzone Fix (화면 우측 끝 조준 사각지대 해결)
- **Chosen**: 몬스터 스폰 범위를 시야 중앙 80% 안전 구역으로 집중(`FAN_MARGIN_RATIO = 0.80`)하고, 조준선(`Crosshair`)의 화면 좌우 도달 범위를 기존 8%~92%에서 3%~97%로 전역 확장.
- **Rationale**:
  - 기존에는 몬스터가 화면 95% 끝단까지 스폰되는 반면, 조준선은 `50 + aimX * 42%` 수식에 의해 최대 92%까지만 이동하도록 제한되어 있어 화면 끝에 있는 몬스터를 물리적으로 조준할 수 없는 사각지대가 발생했습니다.
  - 스폰 범위를 80% 안전 구역으로 모아 3D 모델이 화면 밖으로 삐져나가는 현상을 원천 차단하고, 조준선은 화면 3%~97%까지 넓혀 어떤 가장자리 몬스터도 시원하게 사격할 수 있도록 보장합니다.

## D02. Floor Defense Line and Drop Shadow Grounding (바닥 밀착형 마지노선 및 그림자 바닥 고정)
- **Chosen**: 1.8m 바 카운터 앞 바닥(`y = 0.02`)에 두툼한 폭(약 30cm)의 옐로우/블랙 사선 스트라이프 및 붉은색 네온 발광 경고선(Hazard Stripe Line)을 배치하고, 공중에 떠 있던 몬스터 그림자를 실제 월드 바닥(`y = 0.01`)에 완전히 밀착 고정.
- **Rationale**:
  - 기존에는 플레이어 앞 1.8m 침범 시 라이프가 깎이는데도 바닥에 어두운 얇은 링 하나만 깔려 있고, 몬스터 그림자가 공중(몬스터 높이)에 떠서 이동하여 침범 기준선이 전혀 보이지 않았습니다.
  - 화면을 가리는 공중 UI 대신 펍 바닥에 확실한 공사장/공장형 사선 안전 경고 라인을 깔고, 몬스터 발밑 그림자를 바닥에 밀착시켜 몬스터가 경고선을 밟는 순간을 직관적으로 즉시 인지할 수 있도록 합니다.
