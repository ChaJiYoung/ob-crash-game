# Decisions: 무기 간 균형 (샷건 상향, 리볼버·개틀링 하향)

- Date: 2026-11-07
- Status: Confirmed
- Trigger: 플레이 기록(샷건 3판 연속 패배)과 사용자 의견("샷건은 무기가 MAX가 아니면 못 깬다", "리볼버는 관통이 있어 쉬운데 샷건 탄창이 더 많아야 한다", "리볼버 공격력이랑 개틀링 탄수 정도 괜찮을 것 같다"). 근거 측정: `.memory/references/playtest-2026-11-06-card-farming-fix.md` 7~9절.

## D01. 샷건 탄창 +4
- **Chosen**: `GAME_TUNING.maxAmmoByWeapon.shotgun` 10/10/12/12 → 14/14/16/16.
- **Rationale**: 사용자가 +4를 선택. 리볼버는 관통이 있고 샷건은 없는데 탄창이 같았다. 봇 클리어율 47% → 62~68%.

## D02. 리볼버: Lv.1은 1.0 유지, 레벨업 공격력 상승을 거의 없앰
- **Chosen**: `REVOLVER` 레벨별 `damagePerHit` 1.00 / 1.35 / 1.75 / 2.20 → **1.00 / 1.05 / 1.10 / 1.15**. `weaponDamageScale.revolver`는 1.0, 탄창과 관통은 그대로.
- **Rationale**: 사용자 의견("1.0이 처음인 건 맞고, 레벨별로 올리는 공격력을 거의 안 올리다시피", "관통으로 가져간다"). Lv.1을 낮추면 GREAT 한 발이 1HP 캔을 못 죽여 가이드의 "1레벨 원샷 규칙"이 깨진다(테스트가 잡음). 레벨업의 강해짐은 관통·발사 속도가 담당한다. 봇 클리어율 87~90% → 64~65%. 공격력을 일괄로 0.6배로 낮추면 Lv.2가 Lv.1보다 약해지는 모순이 생겨 제외했다.

## D02-추가. 리볼버 공격력 스케일 1.05
- **Chosen**: `GAME_TUNING.weaponDamageScale.revolver` 1.0 → **1.05**. 레벨별 피해는 1.05 / 1.10 / 1.155 / 1.21(Lv.1도 1.05라 GREAT 한 발의 1HP 캔 원샷은 유지).
- **Rationale**: 플레이 후 사용자가 "리볼버 1.1로"라고 요청했고(공격력 스케일 값으로 이해), 1.1에서 봇 클리어율이 81%로 올라 "1.05?"로 한 단계 낮췄다. 레벨업 상승폭(1.05/1.10/1.15)은 비율로 유지된다.

## D03. 개틀링: 공격력 스케일 하향, 탄창 유지
- **Chosen**: `GAME_TUNING.weaponDamageScale.gatling` 2.0 → **1.5**(처음 1.4로 했다가 플레이 후 "좀만 높이면 맞을 것 같다"는 사용자 의견으로 1.5로 올림, 측정 1.5 + 원래 탄창 = 66%). `maxAmmoByWeapon.gatling`은 30/35/40/50 그대로. 보스 피해 배율(2.2)도 그대로.
- **Rationale**: 사용자 의견("개틀링은 공격력이 낮아서 탄창으로 승부봐야 한다"). 탄창을 반 이하로 줄여도 클리어율이 80%로 거의 안 변했고, 공격력 스케일이 실제 레버였다(1.6에서 73%, 1.4에서 59~70%, 1.3에서 39%). 보스 피해 배율은 클리어율을 바꾸지 못한다.

## D04. 문서·테스트 (코드를 읽고 자동 확정)
- **Chosen**: 무기 가이드 표(샷건 탄창 14~16발, 리볼버 피해 1.05/1.10/1.15, 개틀링 피해 0.35~0.70)와 값을 고정한 테스트(`game-tuning`, `shared-protocol`, `engine-judgment-and-spawn`)를 새 값으로 고친다.

## D05. 스킬 보유 2회 (무기 레벨과 무관)
- **Chosen**: 모든 무기·레벨의 `maxSkillStock`을 2로 한다(이전에는 Lv.4만 2). 무기를 고르는 순간 두 번이 가득 찬 상태로 시작하고(`selectWeapon`이 `skillStock = max`), 쓰면 쿨다운마다 한 번씩 다시 충전된다.
- **Rationale**: 사용자 아이디어("무기를 많이 안 올려도 스킬을 잘 쓰면 깨게", "무기 레벨과 상관없이 2회 충전"). 봇 측정에서 보유 2회만으로는 클리어율이 거의 안 변했지만(평균 사용 횟수는 쿨다운이 정함) 모아 두었다가 보스에 몰아 쓰는 전술이 가능해진다. 보스에게 들어가는 스킬 피해는 아직 작아서(리볼버 Lv.3 한 번에 15, 보스 체력 합 550) 스킬 보스 피해 상향은 별도 결정으로 남긴다.
- **결과**: 샷건 60%, 리볼버 69%, 개틀링 70%(봇, 80판).

## 범위 밖 (결정에 포함하지 않음)
- 샷건 피버 중 발사 속도 상향, 무기 카드 보장, 보스 웨이브 `parTimeSec`·`bossWaveWeight` (사용자 결정 대기)
- 리볼버 관통·탄창 변경, 개틀링 보스 피해 배율 변경, 스킬 피해·쿨다운(스킬을 끄면 샷건 14%·리볼버 18%·개틀링 48%로 영향이 크다는 측정만 기록, 사용자 결정 대기), `RANKING_RULESET_VERSION`(5 유지)

## D06. 스킬 2회 충전 후속 정리 (Opus 5.5 리뷰 반영)
- **Chosen**: Lv.4 달성 시 스킬 2회 공짜 충전을 제거한다. `WeaponSystem.reset()`의 스킬 기본값을 1에서 0으로, 모바일 컨트롤러 초기값을 0/2로 바꾼다. 무기 선택(`selectWeapon`)은 그대로 최대치(2회)로 채운다.
- **Rationale**: 최대치가 이미 모든 레벨에서 2라서 Lv.4 충전은 이중 보상이다. 실제 게임은 항상 무기 선택을 거치므로 reset 기본값 변경은 플레이에 영향이 없다.

## D07. 무기 선택 직후 스킬 0회로 시작
- **Chosen**: `WeaponSystem.selectWeapon`이 스킬을 채우지 않고 0회로 시작한다(첫 충전은 쿨다운 뒤). 최대 보유는 모든 레벨 2회 그대로. 튜토리얼 3단계처럼 스킬이 필요한 곳은 `refillSkillInstant()`로 직접 채운다.
- **Rationale**: 사용자 의도는 "게임 시작할 때 스킬이 찬 채로 시작하지 않게" 하는 것. 봇 클리어율(80판)은 샷건 63%, 리볼버 70%, 개틀링 68%로 거의 변하지 않았다.
