# Decisions: Snap Fire, Fever Auto-Rapid-Fire, Auto Zeroing, and Game Start Synchronization

- Date: 2026-11-02
- Status: Confirmed

## D01. 스냅 발사(위로 휙 올리기) 3차원 가속도 크기 벡터화 및 임계치 완화
- **Chosen**: 3차원 가속도 벡터 노름($\sqrt{x^2+y^2+z^2}$) 기반 감지 및 임계치 8.0 m/s² 완화 (기존 X축 전용 12.0 m/s² 폐기)
- **Rationale**: 사용자가 폰을 권총형 또는 리모컨형 등 다양한 자세로 쥐고 손목을 위로 챌 때 발생하는 가속도가 기기 축에 따라 분산되어 기존의 단일 X축 검사로는 인식이 씹혔습니다. 3축 합성 가속도 크기를 측정하고 문턱값을 8.0 m/s²로 완화하여 손목 스냅이 100% 시원하게 단발 격발되도록 보정합니다.

## D02. 피버 타임(FEVER) 100% 전자동 연사(Auto-Rapid-Fire) 루프
- **Chosen**: 피버 지속 시간(7초) 동안 사용자가 터치패드를 누르지 않아도 매 95ms(초당 약 10발) 간격으로 현재 조준선 좌표에 자동 발사 루프 가동 + 폰 연타 햅틱 진동 피드백
- **Rationale**: 피버 상태일 때 무제한 탄창만 켜지고 자동 발사 루프가 없어 수동으로 터치해야 했던 결함을 해결하고, 모니터의 조준선을 몬스터에게 가져다 대기만 하면 빗발치듯 탄환이 쏟아져 나오는 아케이드 특유의 쾌감을 제공합니다.

## D03. 게임 시작 3초 카운트다운 연동 '자동 영점(Auto Zeroing)' 통합
- **Chosen**: 복잡한 사전 영점 단계(1단계/2단계 글자 모달)를 축소하고, 게임 시작 3초 카운트다운(3, 2, 1) 동안 모니터 중앙을 겨누면 0초 순간 자동으로 정면 영점(0, 0) 고정. 상단 원터치 `🎯 즉시 재영점` 버튼은 상시 유지.
- **Rationale**: 텍스트 위주의 복잡한 영점 화면으로 인한 사용자 혼란을 해소하고, 카운트다운 동안 자연스럽게 화면을 겨누면 시작과 동시에 영점이 잡히는 콘솔형 원스톱 플로우를 제공합니다.

## D04. 모바일-PC 양방향 3초 카운트다운 및 시작 상태 햅틱 동기화
- **Chosen**: 폰이나 PC 어디서든 시작 버튼을 누르면 서버를 통해 `GAME_COUNTDOWN_START` 메시지를 양방향 브로드캐스트하여, 폰 화면에도 대형 카운트다운(3, 2, 1) + 초당 햅틱 진동 + 0초 게임 화면 즉시 전환을 동기화.
- **Rationale**: 폰에서 시작 버튼을 눌렀을 때 폰 화면에 아무런 피드백 없이 버튼만 사라져 멈춘 것처럼 보였던 문제를 완벽히 해결하고, 플레이어가 시작 진행 상황을 시각과 촉각으로 실시간 체감할 수 있도록 합니다.

## D05. PC 브라우저 오디오 자동 재생 정책(AutoPlay Policy) 해제 및 오디오 언락
- **Chosen**: 모바일 컨트롤러 연결 시 및 카운트다운 시작 시 `SoundSynthesizer.unlockAudio()`를 호출하고, PC 화면의 `QRPairingModal`에 "화면 클릭 시 사운드 활성화" 피드백 제공
- **Rationale**: PC 마우스 클릭 없이 모바일만으로 시작했을 때 크롬/사파리의 AutoPlay 정책으로 효과음(카운트다운 음, 총소리, 피버음)이 무음 처리되는 것을 방지합니다.
