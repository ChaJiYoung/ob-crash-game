# Decisions: Cocking Aim Lock and Snap Fire

- Date: 2026-11-02
- Status: Confirmed

## D01. 화면 터치 다운 즉시 조준경 완전 고정 (Instant Aim Freeze)
- **Chosen**: 모바일 화면을 터치하는 순간(`PointerDown`, 코킹 장전) PC 화면의 조준경(Crosshair) 위치를 그 자리에 즉시 동결(Freeze/Lock)하고, 손목을 위로 휙 채어올리는 물리적 반동과 무관하게 고정된 좌표로 탕! 정밀 사격한다.
- **Rationale**: 휙 채어올리는 격발 동작 시 가속도 및 자이로센서의 급격한 각도 변화로 인해 조준선이 허공으로 튀어 타깃을 빗나가는 문제를 원천 차단하고, "조준 ➔ 터치(철컥 조준 고정) ➔ 위로 휙(탕 격발)"의 안정적인 아케이드 손맛을 제공한다.

## D02. 격발 후 단발 리볼버 사이클 (Single-Action Reset)
- **Chosen**: 1발이 발사되는 즉시 조준경 고정이 해제되어 현재 폰이 가리키는 실시간 조준 위치로 즉각 복귀하며, 다음 탄환을 발사하려면 화면에서 손을 뗐다가 다시 눌러서 새 조준을 고정해야 한다.
- **Rationale**: 휙 채어올린 후 손목이 제자리로 내려오는 반동 과정에서 발생하는 원치 않는 연발 오발을 원천 방지하고, 명확한 단발 장전 리듬을 확립한다.

## D03. 피버 타임 중 자유 스윕 조준 (Free Aim Sweep)
- **Chosen**: 피버 타임(FEVER, 초당 10발 자동 연사) 동안에는 조준 고정(Aim Lock)을 비활성화하여, 화면을 터치하고 있더라도 폰을 움직이는 대로 조준선이 자유롭게 따라다니도록 한다.
- **Rationale**: 피버 모드는 몰려오는 적들을 화면 전체로 긁으며 쓸어담는 쾌감이 핵심이므로, 조준선이 한 곳에 묶이지 않도록 보장한다.

## D04. PC 조준경(Crosshair) 조준 고정 시각 피드백 (Lock-on Visual FX)
- **Chosen**: 화면 터치(코킹)로 조준이 고정된 동안 PC 화면의 `CrosshairOverlay`가 선명한 에메랄드 그린 컬러(`#10b981`)로 빛나며 락온(Lock-on) 모서리 괄호가 조준점을 감싸는 시각 효과를 적용한다.
- **Rationale**: 플레이어가 모바일 화면을 보지 않고 PC 모니터만 응시하더라도 "지금 내 조준이 이 자리에 정확히 잠겼다"는 것을 직관적으로 인지할 수 있도록 시각 피드백을 강화한다.

## D05. 로비 대기실(시작 과녁) 동일 코킹 조준 고정 메커니즘 적용 (Lobby Consistency)
- **Chosen**: 로비 대기실(`PAIRING`, `ZEROING`) 화면에서 시작 과녁을 쏠 때도 인게임과 완전히 동일하게 "터치 다운으로 조준 고정 ➔ 휙 채어 시작 과녁 사격"이 일관성 있게 작동하도록 통합한다.
- **Rationale**: 게임 시작 전 로비 과녁을 쏘는 단계에서부터 동일한 조작감과 손맛을 학습할 수 있도록 UX 일관성을 유지한다.
