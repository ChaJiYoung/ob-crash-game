# Plan: Cocking Aim Lock, Snap Fire Stabilization, and Lock-On Visual Feedback

## Goal
모바일 화면 터치(코킹 장전) 시 조준경 좌표를 즉시 동결(Freeze)하여 손목을 휙 채어올리는 격발 반동 시 조준선이 흔들리지 않도록 고정하고, 1발 격발 직후 조준 고정을 해제하여 리볼버 단발 코킹 리듬을 확립한다. 피버 타임에는 자유 스윕 조준을 보장하며, PC 화면 조준경에는 선명한 에메랄드 그린 락온 시각 피드백을 적용하고 로비 시작 과녁 사격까지 동일한 메커니즘을 통합한다.
