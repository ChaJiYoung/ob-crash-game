# Plan: Snap Fire, Fever Auto-Rapid-Fire, Auto Zeroing, and Game Start Synchronization

손목 스냅(위로 휙 채기) 단발 사격의 3차원 가속도 크기 벡터화 및 임계치 완화, 피버 타임 시 100% 전자동 연사(Auto-Rapid-Fire) 루프 가동, 3초 카운트다운 연동 자동 영점(Auto Zeroing) 및 모바일-PC 양방향 카운트다운 햅틱 동기화, PC 오디오 자동 재생 정책 해제를 구현하여 조작감과 시작 경험을 완성한다.
