# Plan: 플레이 소감 반영 (장전 링, 스프링 똥, 피격 효과, 보스 경고, 냉각기 디자인)

## Goal
직접 플레이 소감 다섯 가지를 해결한다.

측정 가능한 완료 기준:
- 장전 링이 8px에 검은 외곽선이고, 장전 중 조준점이 45%로 흐려진다(피버 제외).
- 똥이 바닥에 붙어 위아래로 늘고 줄며 다가오고, 판정이 모델 위치와 일치한다.
- 체력이 줄 때 빨간 번쩍임과 피격음이 나온다(흔들림·진동 없음).
- 보스 등장 때 가로 띠, `WARNING`, 빛줄, 경고음이 나오고 2초 안에 사라진다.
- 소형은 은색 1구, 대형은 검정 3구·금색 레버·왕관이며 이름판에 실제 OB 로고가 있고 둘 다 바닥에 서 있다.
- 문서·도감·스크린샷이 새 동작과 일치하고 `npm test`, `npx tsc --noEmit`, `npm run build`, 라이브 검증이 통과한다. 사람이 직접 플레이로 확인한다.

근거 문서: [결정 문서](../decisions/2026-11-05-playtest-visual-feedback.md)

## 순서의 이유
- P01 먼저: 게임 규칙과 판정을 건드리지 않아 위험이 작다. 눈으로 바로 확인할 수 있다.
- P02는 판정이 바뀐다(똥 판정 위치, 대왕 판정 높이). 봇 시뮬레이션 전후 비교가 필요해 따로 묶는다.
- P03은 마지막: 최종 동작과 모델 기준으로 문구를 쓰고 스크린샷을 찍어야 다시 찍지 않는다.
