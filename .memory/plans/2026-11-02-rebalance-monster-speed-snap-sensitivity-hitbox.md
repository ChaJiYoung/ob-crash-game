# Plan: Rebalance Monster Speed, Snap Sensitivity, and Hitbox Judgment

## Goal
몬스터의 스폰 거리를 24m로 확장하고 이동 속도를 35% 감속하여 조준 가능한 여유 시간을 2배 이상 확보(3.8초 ➔ 7.5~9초)하고, 모바일 발사 스냅(Snap Fire) 가속도 인식 역치를 8.0에서 4.8 m/s²로 완화하여 가벼운 손목 튕김만으로도 즉각 격발되도록 개선한다. 또한 원거리 피격 판정(Hitbox) 투영 배수를 1.5배 확대(2.8 ➔ 4.2)하고 PERFECT 오차 허용치를 완화하여 조준선에 걸친 몬스터를 시원하게 자석처럼 명중시키는 쾌적한 아케이드 건슈팅 손맛을 완성한다.
