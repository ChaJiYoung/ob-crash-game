# Plan: 카드 파밍 차단과 보스 포탄 압박

## Goal
보스를 죽이지 않고 몬스터를 잡으며 카드를 무한히 모으는 플레이(2026-11-06 14:08 샷건 판: 3웨이브 131초, 695킬, 피해 0, 카드 전부 최대치)를 막는다.
- 처치 수 중간 카드를 전 웨이브에서 없앤다(카드는 웨이브 클리어 때만).
- 수리 카드는 +2로 되돌린다(드롭 아이템에서 바 수리 제외는 유지).
- 보스 웨이브 시간 보너스 상한을 2배로 올려(1,400 → 2,800점) 빨리 잡는 쪽이 이득이 되게 한다.
- 보스가 등장한 뒤 시간이 지날수록 포탄 간격이 줄어(3.5초 → 최소 1.5초) 오래 끄는 플레이에 대가를 매긴다.
- 측정 가능한 결과: `npm test`, `npx tsc --noEmit`, `npm run build` 통과. 스톨 봇으로 파밍 시간이 줄어드는 것을 확인. 영향받는 웨이브의 `parTimeSec` 재측정. `RANKING_RULESET_VERSION`은 5 유지.

근거 문서: [결정 문서](../decisions/2026-11-06-card-farming-fix.md)
선행 계획: [보스 체력 상향·병행](./2026-11-06-boss-hp-and-bottle-speed.md)의 D06(보스전 중간 카드)은 이 계획이 대체한다.
