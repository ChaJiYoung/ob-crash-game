# 직접 플레이 기록 (2026-11-04 gameplay-polish-and-perf-optimization)

> 이 문서는 **사람이 직접 플레이해서 채우는 기록**입니다. 자동 검증(봇, 프로파일러)은 "아슬아슬함"을 판단하지 못합니다. 아래 칸은 플레이한 사람이 채워 주세요. 비어 있는 항목은 아직 확인하지 않은 것입니다.

## 실행 방법
```bash
npm run server   # 터미널 1
npm run dev      # 터미널 2 (https://localhost:5173)
```
모니터 2종(외장 50Hz, 내장 레티나)에서 각각, 폰 자이로와 마우스 각각 확인합니다. 첫 서버 실행에서 이전 랭킹이 `data/players.json.ruleset-1.bak`로 백업되고 점수가 초기화됩니다.

## 조정 지침 (`src/shared/gameTuning.ts`)

| 피드백 | 먼저 볼 값 |
|---|---|
| 연타가 아직 쉽다 | `fire.reloadScale`을 2.5 쪽으로 |
| 탭 연타가 쉽다 | "0.35초 미만 연사 처리" 규칙 추가 논의 |
| 개틀링이 쉽다 | `maxAmmoByWeapon.gatling`, `fire.holdDamageByWeapon.gatling` |
| 자이로 조준이 빡빡하다 | `hitZone.scale`을 0.8 쪽으로 |
| 이겼을 때 체력이 많이 남는다 | 웨이브 밀도, `speedPerWave` |
| 너무 어렵다 | 스폰 간격, 보스 체력(`waves[].boss.coolerHp / kingHp`), `boss.damageScaleByWeapon` |
| 보스전이 너무 짧다 | 보스 체력을 올리면 개틀링·리볼버가 3웨이브 보스에서 자주 진다. `damageScaleByWeapon`과 함께 조정 |

수정 후에는 `npm test`와 `npx tsx .memory/references/scripts/simulate-current-decisions.ts 100`을 다시 돌립니다. 빠른 실험은 `TUNE='{...}'`, `BOSS_HP="45,40,50,120"` 환경 변수로 파일을 고치지 않고 할 수 있습니다.
