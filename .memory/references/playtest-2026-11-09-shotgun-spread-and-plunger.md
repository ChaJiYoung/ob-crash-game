## 3. 판정

- 합격선: **G − 3 ≤ S ≤ R + 3**
- 대입: 56 − 3 = 53 ≤ 90 ≤ 90 + 3 = 93 → **통과**
- 그래서 값은 바꾸지 않았다(조정 0회, D08 규칙의 I02 조정은 실행하지 않음).
- 참고: S와 R이 같은 90%로 나왔다. 이상적인 순서 G < S < R에서 S와 R은 오차 범위 안에서 구분되지 않는다. 합격선 기준으로는 서열이 뒤집히지 않은 것이다.
- 참고: 게틀링(56%)은 2026-11-07 측정(68%)보다 낮고 리볼버(90%)는 2026-11-07 측정(70%)보다 높다. 이번 측정은 같은 세션에서 세 무기를 다시 돌린 값만 판단에 쓴다.

## 5. I03 최종 선택

- 최종 값: **시작값 유지** (아래 값을 바꾸지 않음)
  - 추가 명중 마릿수 2 / 2 / 3 / 3, 비율 10 / 15 / 20 / 25%, 반경 0.30
  - 폭발 피해 0.7 / 0.8 / 0.9 / 1.0, 보스 피해 4 / 5 / 6 / 6
  - 샷건 피해 스케일 1.0
- 최종 클리어율: **S 90% / G 56% / R 90%**
- 이유: 합격선을 만족하고, 값을 바꾸면 측정 근거를 새로 잡아야 한다. 샷건이 이번 측정에서 리볼버와 같은 수준이라 값을 올릴 이유가 없다.
- 변경 파일: 없음 (`gameTuning.ts`, 테스트 2개, 가이드 문서는 그대로).
- 검증: `npm test` 119 파일 968 테스트 통과, `npx tsc --noEmit` 오류 없음.

## 6. 다음에 볼 점

- S와 R이 같은 값(90%)이라 샷건이 리볼버를 확실히 이기지 못한다는 점은 기록으로만 남긴다. 정식 서열이 "리볼버보다 약간 강하거나 같음"으로 충분한지는 플레이 피드백으로 확인한다.
