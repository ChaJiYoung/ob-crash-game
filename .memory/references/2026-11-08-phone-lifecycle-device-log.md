# 실기기 검증: 폰 수명주기 (2026-11-08)

- 기기: iPhone 13 mini, Safari (QR 스캔 후 Safari로 열림)
- 서버: `tsx watch`, 판정 추적 로그(`TEMP(sensor-debug)`) 사용

## 확인된 기기 동작
- 화면을 잠그면 2~3초 안에 소켓이 닫히고, 잠금을 풀면 Safari가 페이지를 새로 연다(`pageAgeS`가 0부터 다시 시작).
- 새 페이지는 센서 권한이 없어, 사용자가 초록 버튼을 눌러야 `deviceorientation`이 온다.
- 따라서 이 기기에서는 "같은 페이지 복귀(돌아가기 버튼)"가 아니라 "새 페이지 + 초록 버튼"이 실제 복귀 경로다.

## 발견해 고친 문제
1. 서버 재시작 뒤 PC가 다시 붙지 않아 폰이 `ROOM_NOT_FOUND`로 무한 반복 → PC 자동 재연결(`b5ae0a9`).
2. 숨겨진 폰의 드문 프레임이 PC를 재개시킬 위험 → 끊김 표시는 영점 신호로만 해제(`3e9e178`).
3. 재인증(`CONTROLLER_PAIRED`)만으로 PC가 3·2·1 재개 → 폰이 센서 없이 PAD로 넘어가 조준 고정 → 재개는 `ZERO_CALIBRATED`에서만, 센서 없는 폰은 카운트다운에 권한 화면을 건너뛰지 않음(`5afca89`).

## 남은 문제
- 화면이 켜진 채 프레임만 끊겼다 돌아오는 경우 폰에 버튼이 뜨지 않음(return-button D08).
- 돌아가기 버튼은 페이지를 유지하는 기기에서만 보인다. 이 기기에서는 초록 버튼이 같은 역할을 한다.
