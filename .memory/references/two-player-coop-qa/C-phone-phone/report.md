## 3. 발견된 문제 (BUG)

### [BUG-C-01] 폰 사격 이벤트 수신 시 `TypeError: Illegal invocation` 콘솔 에러 발생
- **분류**: BUG (비차단성 브라우저 콘솔 오류)
- **심각도**: Low / Warning (사격 동작 및 게임 흐름 자체는 유지되나 콘솔 에러 발생)
- **발생 위치**: `src/pc/input/PlayerActionProcessor.ts:52:40` (`this.getNow()`)
- **로그 내용**:
  ```
  CONSOLE ERROR: Error handling WebSocket message TypeError: Illegal invocation
      at PlayerActionProcessor.send (https://127.0.0.1:5203/src/pc/input/PlayerActionProcessor.ts:52:40)
      at PhoneAdapter.onSensorFrame (https://127.0.0.1:5203/src/pc/input/PhoneAdapter.ts:53:12)
      at socket.onmessage (https://127.0.0.1:5203/src/pc/PCGamePage.tsx:576:43)
  ```
- **원인 분석**:
  - `PlayerActionProcessor.ts` Line 50~52:
    ```typescript
    private getNow(): number {
      return this.ctx.now ? this.ctx.now() : (typeof performance !== 'undefined' ? performance.now() : Date.now());
    }
    ```
  - 번들러(Vite/ESBuild)가 `performance.now()` 호출을 `(0, performance.now)()` 형태로 context 없이 트랜스파일하는 경우, Web API 내장 메서드 특성상 `this !== window.performance`로 판정되어 브라우저에서 `TypeError: Illegal invocation` 예외를 던집니다.
  - `PhoneAdapter.ts` Line 70에도 동일한 패턴이 존재합니다.
- **권장 조치 방안**:
  - `performance.now()` 대신 `window.performance.now()`를 명시하거나 `performance.now.bind(performance)` 형태로 안전하게 바인딩할 것.
