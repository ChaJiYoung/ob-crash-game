## 조정 위치 (모두 `src/shared/gameTuning.ts`)
| 증상 | 바꿀 값 |
|---|---|
| 스킬이 아직 느리다 / 너무 잦다 | `skillCooldownMsByLevel` |
| 오비가 아직 어렵다 / 너무 쉽다 | `monsters.obi.guardUpMs`, `guardDownMs` |
| 장전이 답답하다 / 너무 관대하다 | `fire.reloadScale` |
| 탄창이 빡빡하다 / 넉넉하다 | `maxAmmoByWeapon` |
| 보너스 기준이 안 맞다 | `waves[i].parTimeSec` |
| 전체가 너무 쉽다 | 위 값들을 조금씩 되돌리거나 `speedPerWave`, 웨이브 `totalSpawns` |

값을 바꾼 뒤에는 `npm test`(docs-sync가 무기 가이드 표를 검사)와 `npx tsx .memory/references/scripts/simulate-current-decisions.ts 60`을 다시 돌린다.
