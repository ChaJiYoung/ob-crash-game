> 아래 "사람이 채움" 표는 **직접 플레이한 사람이 채우는 칸**입니다. 에이전트가 대신 통과로 표시하지 않습니다.
> 점수 차별화 계획(`2026-11-05-score-differentiation`)의 대기 중인 플레이 확인(`playtest-2026-11-05.md`)도 이번 플레이로 함께 닫습니다.

## 이번에 바뀐 것
1. 스킬 쿨타임 35/31/27/23초 → **21/19/16/14초**
2. 오비 방패 **0.8초 올림 / 2.4초 내림** (내려간 비율 50% → 75%)
3. 장전 배율 2.0 → **1.2** (샷건 Lv.1 약 1.7초, Lv.4 약 1.3초)
4. 탄수 샷건·리볼버 **10/10/12/12**, 개틀링 **20/25/30/35**
5. PC 조준점 둘레에 **장전 게이지 링**(피버 중 제외), 피버 중·개틀링 조준점 링이 실제로 회전
6. 웨이브 기준 시간 14/18/20/24/22/23/48초, 랭킹 규칙 v4 (서버를 켜면 기존 랭킹이 `data/players.json.ruleset-<이전 버전>.bak`로 백업되고 점수가 초기화됨. 지금 `players.json`에는 규칙 버전이 없어 v1로 취급되므로 `ruleset-1.bak`이 된다)

|---|---|

# 무기 스킬 개편 추가분 (2026-11-05, weapon-skill-rework)

> 위의 스킬·방패·탄창 조정과 점수 차별화 계획의 플레이 확인을 **이번 한 번의 플레이로 함께** 닫는다. 사용자는 표를 직접 채우지 않고 채팅으로 느낌을 말해도 된다. 에이전트는 들은 내용을 기록만 하고 대신 통과로 판단하지 않는다.

## 이번에 더 바뀐 것
1. 리볼버 스킬 `오프너 참격`: 세로 초승달 칼날이 부채꼴로 곧게 날아가 닿은 몬스터만 베고 포탄도 벤다. 칼날 3 / 3 / 5 / 7개, 관통 0 / 1 / 1 / 2, 피해는 평타 한 발과 같음
2. 개틀링 스킬 `거품 해일`: 작은 거품이 필드 전체로 퍼지며 3 / 3.5 / 4 / 5m 뒤로 미끄러뜨리고 둔화, 피해는 낮음
3. 리볼버 평타 관통으로 맞은 뒤쪽 몬스터에도 찌그러짐·파편이 보임
4. 보스는 기절·둔화에 면역(뚫어뻥이 박히지 않고 튕김), 공격력 강화 카드가 스킬 피해에도 적용
5. 샷건·개틀링의 밀어내기가 16m 밖 몬스터를 앞으로 끌어오던 버그 수정
6. 웨이브 기준 시간 15 / 19 / 21 / 24 / 23 / 24 / 50초 (랭킹 규칙은 v4 그대로)
