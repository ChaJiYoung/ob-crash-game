# 직접 플레이 기록 (2026-11-05 score-differentiation)

> 이 문서는 **사람이 직접 플레이해서 채우는 기록**입니다. 봇은 "점수 차이가 실제 실력 차이를 반영하는지", "폰 자이로로 낙하 부하에 대응할 수 있는지"를 판단하지 못합니다. 아래 칸은 플레이한 사람이 채워 주세요. 비어 있는 항목은 아직 확인하지 않은 것입니다.

## 실행 방법
```bash
npm run server   # 터미널 1
npm run dev      # 터미널 2 (https://localhost:5173)
```
폰 자이로와 마우스 각각 확인합니다. 첫 서버 실행에서 이전 랭킹이 `data/players.json.ruleset-1.bak`로 백업되고 점수가 초기화됩니다(닉네임 유지).

## 이번에 바뀐 것 (플레이할 때 볼 것)
1. 웨이브를 깰 때마다 화면 위쪽에 `WAVE n CLEAR · 시간 · +보너스`가 약 2.5초 나옵니다. 웨이브당 최대 700점(보스 웨이브 1,400점), 기준 시간의 1.6배에서 0점.
2. 결과 화면에 점수 내역(기본 / 시간 보너스 / 정밀도 보너스)이 나옵니다.
3. 보스 부하가 보스 뒤가 아니라 **필드 6~14m 곳곳에 위에서 떨어집니다**(약 1.2초 낙하, 바닥에 착지 링 표시). 한 번에 3마리, 소환 간격은 8초에서 시작해 보스전이 길어질수록 5초까지 짧아집니다.
4. 피버는 탄창 무한 + 점수 1.5배, 명중은 모두 GREAT 판정(피해·연사 속도는 평소).

## 조정 방법
수치는 `src/shared/gameTuning.ts` 한 곳만 고칩니다.
- 시간 보너스: `score.timeBonus`(`maxPerWave`, `bossWaveWeight`, `zeroAtParMult`), `waves[i].parTimeSec`
- 정밀도 보너스: `score.precisionBonus.k`
- 보스 낙하·소환: `boss.minionDrop`(`minRadiusM`, `maxRadiusM`, `dropMs`), `boss.summonAccel`, `boss.summonCount`, `boss.summonMaxActive`
- 조정 뒤 `npm test`와 `npx tsx .memory/references/scripts/simulate-current-decisions.ts 60 all 보통`, `measure-wave-times.ts`, `boss-strategy-compare.ts`를 다시 돌립니다.
