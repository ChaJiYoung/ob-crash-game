### 3-2. DIFF-1 상세 설명

- **현상**: 리볼버 매치에서 Wave 5 보스전이 **316초**(엔진 대비 3.1배), Wave 7 보스전이 **160초**(엔진 대비 2.1배) 소요됨.
- **원인 분석**:
  1. 보스전 직전 rAF가 56, 59로 측정되어 시스템 부하로 인한 프레임 저하가 아님이 명확히 확인됨.
  2. 봇 전략이 `minions-first`(보스보다 착지한 일반 몬스터 우선 제거)인데, 리볼버는 탄창 수가 10발로 적고 단발 사격 특성상 쫄 몬스터가 계속 쏟아져 나오는 Wave 5와 Wave 7에서 보스 타겟팅 기회가 줄어들어 딜 누적이 지연됨.
  3. 반면 광역 펠릿이 있는 샷건과 연사력이 높은 개틀링은 쫄을 빠르게 정리하고 보스를 타격할 수 있어 엔진 봇 평균보다 빠르게 클리어됨.
  4. 이는 2차 QA(R2)의 QA-D 보고서에서도 동일하게 관찰된 바 있음(R2: W5 274s, W7 366s).
