## 2. 생성 및 서빙 방식
- 해상도: `1024 x 512` (캔/실린더 전개도 표준 2:1 비율)
- 포맷: JPEG (Quality 95%)
- 서빙 경로: Vite 정적 자산 경로 `/textures/labels/{kind}.jpg`
- 로딩 전략: Three.js `TextureLoader`를 통해 로드하며, 오프라인 또는 Node 환경(Vitest)에서는 Canvas 절차적 텍스처로 자동 폴백되도록 구현됨.
