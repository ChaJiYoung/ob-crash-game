# 비어 크러셔 요구사항 분석서

버전 1.1 (권총 파지·통합 터치·부채꼴 스폰·고유번호 로그인·PERFECT 확정본) · 2026-11-01 · 단계: 요구사항 구체화 및 화면·타겟 확정 · 대상: 개발팀

> 수치는 지금까지 만든 브라우저 3D 목업(`beer_crusher_mockup_v2.html` 및 `stage-concepts-preview.html`)의 검증된 기본값입니다. 튜닝 표시가 있는 값은 실제 폰으로 테스트한 뒤 조정합니다. 상세 기술 아키텍처와 구현 명세는 함께 작성된 `docs/비어 크러셔 상세설계서.md`에서 정의합니다.

## 1. 문서 개요

**목적**: 오비맥주 프로젝트용 모션 슈팅 게임 비어 크러셔의 기능, 게임 로직, 실제 OB맥주 제품 기반 3D 타겟/스테이지, 권총 파지 센서 방향 및 통합 터치 조작, 폰 고유번호 기반 로그인/닉네임 시스템, PC·스마트폰 화면 구성, 연출과 사운드, 비기능 요건을 구체화해 개발 착수의 기준으로 삼습니다.

**범위**: PC 게임 화면(16:9 풀스크린 3D + 오버레이 HUD + TOP 5 랭킹), 스마트폰 권총 그립 컨트롤러, 두 기기의 실시간 연결 및 폰 고유번호 기반 로그인(신규 회원 닉네임 등록), 게임 규칙, 상태별 상세 화면 구성, 연출과 사운드, 3D 에셋.

**제외**: 외부 클라우드 서버 운영과 대규모 배포 인프라, 폰 단독 3D 플레이, 다인 동시 플레이.

| 용어 | 뜻 |
| --- | --- |
| 권총 파지 (건 그립) | 총을 쏘듯 **휴대폰 윗부분(상단 베젤)이 모니터를 향하고, 액정 화면은 좌측(왼쪽)을 바라보게** 세워 쥐는 파지 자세 |
| 에어 포인터 | 권총 파지 상태에서 폰 윗부분(총구)이 겨눈 방향대로 PC 화면의 조준선이 움직이는 방식 |
| 영점 | 폰 윗부분을 모니터 화면 정중앙에 겨눈 자세를 조준선 중앙의 기준으로 정하는 것 |
| 스냅 | 권총 파지 상태에서 손목을 위로 탁 쳐올리는 반동 동작. 단발 사격 입력 |
| 오차율 | 조준점과 대상 중심 사이 거리 ÷ 대상 판정 반경. 0은 정중앙, 1은 가장자리 |
| PERFECT / GREAT / GOOD | 오차율에 따른 3단계 정밀 판정 등급 (`0.15 이하` PERFECT / `0.45 이하` GREAT / `1.0 이하` GOOD) |
| 피버 | 게이지 100 완충 시 화면 더블 터치로 발동하는 8초 자동 관통 연사 모드 |
| 웨이브 | 부채꼴 시야 전체에서 등장하는 정해진 수량의 적을 모두 처치하면 끝나는 한 단계 |

## 2. 프로젝트 개요

- **프로젝트명**: 비어 크러셔 (Beer Crusher)
- **장르**: 1인칭 고정 시점 3D 아케이드 모션 슈팅
- **콘셉트**: 오비맥주 브루어리 & 네온 펍 바 카운터(1.8m 방어선) 안에서 **부채꼴 시야 전체(반경 28m 원호, 왼쪽 끝~오른쪽 끝)**에서 밀려오는 **오비맥주 실제 캔 제품(오비라거·카스 라이트·필굿·한맥), 거품 가득한 생맥주 유리잔, 업소용 OB 생맥주 냉각기(보스)**를 권총처럼 쥔 스마트폰으로 겨누어 쏘아 부수며 스트레스를 날리는 체감형 액션
- **플랫폼**: PC 브라우저(3D 게임 화면, 소리, 랭킹, 마우스/키보드 즉시 시작 겸용) + 스마트폰 브라우저(권총 파지 모션·터치 컨트롤러). 앱 설치 없이 QR로 연결
- **1판 길이 목표**: 웨이브 5 도달까지 약 8~12분 (튜닝)
- **성공 기준**: (1) QR 스캔 및 로그인부터 첫 발사까지 60초 이내 (2) 폰 화면을 보지 않고 모니터만 보며 조작 가능 (3) 권총처럼 폰을 쥐고 엄지나 반대손으로 직관적 플레이

## 3. 시스템 구성, 연결 및 폰 고유번호 로그인

### 3.1 역할

| 구성 | 역할 |
| --- | --- |
| PC 화면 | 16:9 풀스크린 Three.js 3D 게임 렌더링, 네 모서리 아케이드 오버레이 HUD, 로그인 유저 환영 배너 및 TOP 5 랭킹 보드, 효과음/배경음 합성 출력, 게임 규칙 전체 처리 |
| 스마트폰 | 권총 파지 기준 방향 센서(`DeviceOrientation`)와 가속도 센서(`DeviceMotion`) 값, 폰 고유번호(`deviceId`) 인증 및 신규 닉네임 입력, 통합 터치 입력(연사 홀드·피버 더블탭·영점), 진동 및 시각 피드백 담당. 3D 게임 화면은 그리지 않음 |
| 연결 & 서버 | PC가 만든 로컬 HTTPS 세션 QR을 폰으로 스캔해 WebSocket 1:1 실시간 연결 및 플레이어 DB(`data/players.json` 또는 SQLite)에 고유번호·닉네임·최고 기록 저장 |

### 3.2 페어링 및 폰 고유번호 기반 로그인 흐름

1. **세션 QR 및 랭킹 대기 (PC)**: PC에서 게임 페이지를 열면 고유 세션을 만들고 화면 중앙에 **QR 코드(유효 5분, 1회용)**와 **명예의 전당 TOP 5 랭킹 보드**를 표시한다. (스마트폰 없이 테스트할 경우 `[PC 마우스/키보드로 바로 시작]` 버튼으로 즉시 진입 가능)
2. **QR 스캔 및 폰 고유번호(`deviceId`) 식별 (폰 → 서버)**:
   - 폰으로 QR을 스캔하면 컨트롤러 웹 화면(`/controller?session=...`)이 열리고, 폰의 고유 식별번호(`deviceId`: 영구 UUID + 기기 핑거프린트)를 추출해 서버로 전송한다.
3. **신규 회원 vs 기존 회원 로그인 분기**:
   - **신규 회원 (처음 접속한 폰 고유번호)**: 폰 화면에 **`[🍺 신규 플레이어 등록 — 닉네임을 입력해주세요 (2~10자)]`** 입력창이 뜨고, 닉네임 입력 즉시 회원 등록 및 로그인이 완료된다.
   - **기존 회원 (이미 등록된 폰 고유번호)**: 별도 입력 없이 **자동 로그인**되어 기존 닉네임과 내 최고 기록(`최고 점수 · 최고 웨이브`)을 즉시 불러온다. (원할 경우 작은 `[닉네임 변경]` 버튼으로 수정 가능)
   - 로그인이 완료되면 PC 화면에도 **`"🍺 [닉네임]님 환영합니다! (개인 최고 기록: 18,400점)"`**이 표시된다.
4. **센서 권한 및 권총 파지 영점 맞추기**:
   - 폰에서 센서 사용 허용 버튼(iOS 필수)을 누른 뒤, **휴대폰 윗부분을 모니터 정중앙에 겨누고 화면은 좌측을 바라보게 쥔 상태(권총 파지)**에서 화면을 터치해 정면 영점을 맞춘다.
5. **카운트다운 및 웨이브 시작**: 영점이 끝나면 PC에서 3초 카운트다운(`3 → 2 → 1 → CRUSH!`) 후 웨이브 1이 시작된다.
6. **결과 저장 및 재시작**: 게임이 끝나면 해당 플레이어(`deviceId`)의 최고 점수와 랭킹이 자동 갱신되며, 같은 연결로 즉시 다시 시작할 수 있다.

### 3.3 연결 및 로그인 요구사항

| ID | 요구사항 |
| --- | --- |
| FR-CON-01 | 세션 하나에 폰 한 대만 연결한다. 추가 연결 시도는 거부하고 안내한다. |
| FR-CON-02 | QR에는 세션 식별 정보와 로컬 HTTPS 접속 URL만 담는다. |
| FR-CON-03 | 폰은 센서 값을 초당 약 60회(60Hz) PC로 보낸다. |
| FR-CON-04 | 입력이 화면에 반영되기까지 지연 목표는 100ms 이하(같은 네트워크 기준)이다. |
| FR-CON-05 | 연결이 끊기면 게임을 즉시 일시정지하고 재접속 QR과 30초 카운트다운을 안내한다. 30초 안에 돌아오면 이어서 하고, 넘기면 결과 화면으로 간다. |
| FR-CON-06 | 플레이 중 폰 화면이 꺼지지 않게 한다(`Screen Wake Lock API`). |
| FR-CON-07 | 연결 상태와 왕복 지연(ms)을 PC와 폰 양쪽에 실시간 표시한다. |
| FR-CON-08 | 센서 권한 거부, HTTP 비보안 접속, 센서 미지원 시 원인과 해결 방법을 화면에 안내한다. |
| FR-AUTH-01 | QR 접속 시 폰 고유번호(`deviceId`)로 사용자를 자동 식별하며, 미등록 기기(신규 회원)일 때만 닉네임 입력 화면을 노출해 회원가입/로그인 처리한다. |
| FR-AUTH-02 | 등록된 회원의 닉네임, 최고 점수, 최고 도달 웨이브, 누적 플레이 횟수를 서버 로컬 스토리지(JSON/SQLite)에 영구 저장하고 TOP 5 랭킹에 반영한다. |

### 3.4 지원 환경

- PC: 최신 Chrome, Edge (1280×720 이상, 16:9 권장)
- 폰: Android Chrome, iOS Safari. 모바일 센서를 쓰기 위해 로컬 개발/시연 서버에 보안 연결(HTTPS)을 기본 적용한다.
- 진동: Android Chrome(`navigator.vibrate`)을 지원한다. iOS는 웹 진동을 지원하지 않으므로 사운드와 화면 효과로 대체한다.

## 4. 조작 요구사항 (권총 파지 센서 인식 & 통합 터치)

### 4.1 권총 파지 자세 및 센서 방향 규격

플레이어는 스마트폰을 리모컨처럼 눕혀 쥐지 않고 **실제 권총을 쏘는 자세**로 파지한다:
- **휴대폰 윗부분 (상단 스피커/전면 카메라 쪽 = 기기 `+Y축`)**: **PC 모니터 정면(총구 방향)**을 바라보게 겨눈다.
- **휴대폰 액정 화면 (기기 `+Z축`)**: 휴대폰을 세워서 **액정이 좌측(왼쪽)**을 바라보게 한다. (오른손으로 쥐었을 때 엄지나 왼손 손가락으로 왼쪽을 향한 액정을 바로 터치할 수 있는 방향)
- **휴대폰 오른쪽 긴 테두리 (기기 `+X축`)**: **천장(위쪽)**을 향한다.

| ID | 요구사항 |
| --- | --- |
| FR-INP-01 | 권총 파지 상태에서 **폰 윗부분(`+Y축` 총구 벡터)**의 3D 회전 변화를 화면 조준선 좌표로 바꾼다. 좌우 방위각 `±35°`, 상하 고도각 `±20°`가 화면 가장자리에 대응하고, 범위를 넘으면 가장자리에서 멈춘다. (튜닝) |
| FR-INP-02 | 영점 버튼을 누른 순간의 권총 파지 자세(`+Y축` 방향 벡터)를 화면 정중앙(`W/2, H/2`) 기준으로 재설정한다. 영점 재설정 버튼은 폰 앞쪽(모니터 쪽 끝단 15%)에 항상 보인다. |
| FR-INP-03 | 조준선은 센서 값을 그대로 따르지 않고 부드럽게 따라간다. 매 프레임 목표까지 거리의 25%(`LERP = 0.25`)씩 접근한다. |
| FR-INP-04 | 시간이 지나면 조준이 조금씩 틀어질 수 있으므로, 웨이브 휴식마다 영점 재조정을 안내한다. |
| FR-INP-05 | 권총 파지 상태에서 손목을 위로 탁 쳐올리는 **단발 스냅**은 천장을 향하고 있는 **폰 오른쪽 긴 테두리 방향(`+X축`)의 위쪽 선형 가속도(약 12 m/s² 이상) 및 상향 피치 각속도**로 인식한다. |

### 4.2 입력 규격 (재장전 자동화 & 연사·피버 통합 터치)

플레이어가 모니터만 보면서 조작할 수 있도록 **수동 재장전을 없애고(자동 재장전 전용)**, 폰 화면의 85%를 차지하는 **단일 통합 터치 영역**에서 연사(꾸욱 누르기)와 피버 발동(두 번 터치)을 모두 처리한다.

| 입력 | 동작 (스마트폰 권총 파지) | 동작 (PC 단독 모드) | 인식 조건 | 결과 |
| --- | --- | --- | --- | --- |
| **단발** | 손목으로 총구를 위로 스냅 | 마우스 좌클릭 또는 `Space` | 위 방향(`+X축`) 가속도 약 12 m/s² 이상 (튜닝) | 1발 발사. 직후 0.15초 조준 고정(`FREEZE`), 0.35초간 스냅 재인식 금지(`FLICK_CD`) |
| **연사** | 통합 터치 영역 **꾸욱 누르기 (Hold)** | `F` 키 홀드 또는 마우스 좌클릭 홀드 | **0.25초 이상** 터치 유지 | 초당 8발(0.125초 간격) 연속 발사. 손을 떼면 즉시 중단 |
| **피버 발동** | 통합 터치 영역 **두 번 터치 (더블탭)** | `E` 키 또는 우클릭/더블클릭 | **피버 게이지 100 완충 상태**에서 **0.3초 이내 연속 2회 탭** | 8초 피버 자동 관통 연사 발동 |
| **자동 재장전** | 탄 10발 소진 시 자동 작동 (수동 장전 없음) | 탄 10발 소진 시 자동 작동 | 탄 0 도달 즉시 | **1.2초 자동 재장전** |
| **영점 재설정** | 폰 앞쪽 끝단(15%) `영점` 버튼 터치 | `C` 키 | 언제든 | 현재 총구(`+Y축`) 자세를 화면 중앙으로 재설정 |

### 4.3 입력 충돌 방지 규칙

- 단발 스냅 인식 후 **0.15초 동안은 조준선 이동을 무시**한다. 스냅 때 총구가 위로 들리며 조준점이 튀는 것을 막기 위해서다.
- 통합 터치 영역을 **0.25초 이상 꾸욱 누르면 연사**가 시작되고, **0.25초 미만으로 짧게 두 번 연속(0.3초 이내) 터치하면 피버 발동**으로 인식한다.
- 만약 피버 게이지가 100이 안 된 상태에서 한 번 탭하거나 더블탭하면 아무 일도 일어나지 않는다.
- 피버 중에는 초당 18발 자동 연사가 입력을 대체하므로 단발과 연사 입력은 별도 효과가 없다.
- 자동 재장전 중(1.2초)에는 발사 입력을 무시한다. 피버 중에는 탄이 무한이므로 재장전이 없다.

### 4.4 진동 (Android) 및 시각/사운드 피드백 (iOS)

| 상황 | 패턴 |
| --- | --- |
| 단발 | `40ms` 1회 |
| 연사 | 발사마다 `15ms` 펄스 |
| 자동 재장전 시작/완료 | `30ms - 40ms 쉼 - 30ms` 2연타 |
| 피격 | `200ms` 강한 1회 |
| 피버 발동 | `60-30-60-30-60ms`, 피버 중에는 짧은 연속 펄스 |

## 5. 게임 로직 설계

### 5.1 상태 흐름

`대기(QR 표시 & TOP 5 랭킹)` → `폰 연결 & 고유번호 로그인(신규 회원 시 닉네임 입력)` → `권총 파지 영점 대기` → `카운트다운 3초` → `웨이브 진행` ⇄ `휴식 5초` → `게임 오버(체력 0)` → `결과 및 랭킹 갱신` → `다시 시작`. 연결이 끊기면 어느 단계에서든 일시정지한다.

### 5.2 기본 스탯

| 항목 | 값 |
| --- | --- |
| 체력 | 10칸. 일반 적(캔·생맥주잔) 도달 `-1`, 보스(생맥주 냉각기) 도달 `-3` |
| 탄창 | 10발. 발사 1회에 1발 소모 |
| 자동 재장전 | 탄 0 도달 시 즉시 1.2초 자동 재장전, 조준선 하단 진행 막대 표시 |
| 피버 게이지 | 0 ~ 100 (**100 완충 시 빗나가도 절대 내려가지 않음**) |

### 5.3 발사 처리 순서

1. 입력을 받는다. 게임이 진행 중이 아니면(일시정지, 결과) 무시한다.
2. 자동 재장전 중(`reloadT > 0`)이면 무시한다.
3. 피버 중에는 탄을 소모하지 않고, 일반 상태에서 탄 1발을 소모하며 발사 연출과 진동을 낸다.
4. 조준점 기준으로 화면 투영 판정(5.4)을 수행한다.
5. 결과를 처리한다. 적중이면 등급(`PERFECT` / `GREAT` / `GOOD`)에 따라 점수, 콤보, 게이지, 처치 시 드롭을 처리한다. 아이템이면 효과를 적용한다. 아무것도 없으면 빗나감 처리한다.
6. 탄이 0이 되면 즉시 **1.2초 자동 재장전**을 시작한다.

### 5.4 판정 (`PERFECT` / `GREAT` / `GOOD` 3단계)

- 조준점과 대상 중심이 화면에 보이는 위치 사이의 거리가 대상의 판정 반경(화면 크기로 환산) 안이면 적중이다.
- **오차율(`거리 ÷ 판정 반경`)에 따른 3단계 정밀 판정**:
  - **오차율 `0.00 ~ 0.15 이하`**: **`PERFECT`** (정중앙 초정밀 적중!)
  - **오차율 `0.15 초과 ~ 0.45 이하`**: **`GREAT`**
  - **오차율 `0.45 초과 ~ 1.00 이하`**: **`GOOD`**
- 판정 반경 안에 적도 아이템도 없으면 **빗나감(Miss)**이다.
- 대상이 겹치면 카메라에 가장 가까운 하나만 맞는다. 적이 있으면 아이템보다 적이 먼저다. 적이 없고 아이템만 있으면 아이템을 얻는다.
- 피버 중에는 조준점 반경 안의 적과 아이템을 모두 맞힌다. (**관통**)
- 자동 조준 보정은 없다. 정밀도는 플레이어의 조준에 달려 있다.

### 5.5 점수와 콤보

| 항목 | 값 |
| --- | --- |
| **PERFECT 적중** (오차율 ≤ 0.15) | **150점** |
| **GREAT 적중** (오차율 ≤ 0.45) | **100점** |
| **GOOD 적중** (오차율 ≤ 1.00) | **50점** |
| 처치 보너스 | 일반 적 50점 (보스 생맥주 냉각기 500점) |
| 아이템 획득 | 20점 |

- 체력을 깎기만 한 적중도 점수와 콤보에 포함한다.
- 콤보는 적중마다 1씩 오르고, 빗나감이나 피격 시 0이 된다.
- 콤보 달성 팝업: `5 NICE!`, `10 AWESOME!`, `15 UNSTOPPABLE!`, `20 LEGENDARY!`. 20 이후에는 5단위마다 `LEGENDARY!`.
- 콤보 배율은 점수에 곱하지 않고 피버 게이지 충전에만 쓴다. 5 이상 `1.5배`, 10 이상 `2배`.

### 5.6 피버 (100% 완충 시 감소 방지 규칙 포함)

| 항목 | 값 |
| --- | --- |
| 충전 | **PERFECT `+30`**, **GREAT `+20`**, **GOOD `+10`** (콤보 배율 1.5x / 2.0x 적용, 최대 100) |
| 감소 및 **완충 고정(Lock)** | 게이지가 100 미만(`0 ~ 99`)일 때는 빗나감 시 `-5` 감소한다. **단, 게이지가 `100`까지 다 차면 잘못 맞춰도(빗나가도) 게이지가 내려가지 않고 `100`으로 계속 유지된다!** (피격 시에도 게이지는 깎이지 않고 콤보만 0이 됨) |
| 발동 조건 | 게이지 100 완충 상태에서 **폰 통합 터치 영역 두 번 터치(더블탭)** (PC는 `E`키/더블클릭) |
| 지속 | 8초. 게이지는 8초에 걸쳐 0으로 줄고 종료 시 0 |
| 자동 연사 | 초당 약 18발(0.055초 간격). 버튼을 누르고 있을 필요 없이 조준선만 움직이면 된다 |
| 효과 | 탄 무한, 재장전 없음, 관통, 빗나감 페널티 없음, 피버 중 게이지 충전 없음 |
| 연출 | 화면 테두리 금색 발광, 배경음 가속, 연속 진동 |

### 5.7 피격

- 적이 플레이어 앞 도달선(`1.8m` 원목 바 카운터 호)에 닿으면 피격이다. 그 적은 사라진다.
- 보호막이 있으면 피해를 막고 보호막이 사라진다.
- 피격 시 콤보 0, 붉은 화면 테두리, 진동. 피버 게이지는 유지한다.
- 체력이 0이면 게임 오버다.

### 5.8 웨이브와 부채꼴(시점 모양) 방사형 스폰

| 웨이브 | 최대 동시 | 총량 | 등장 구성 (6종 타겟) | 특징 |
| --- | --- | --- | --- | --- |
| W1 | 3 | 10 | 오비라거 캔, 필굿 캔, 생맥주잔(소수) | 부채꼴 조준과 스냅 단발 적응 |
| W2 | 4 | 15 | W1 + 카스 라이트(날개 캔) | 공중 타겟으로 상하·좌우 부채꼴 조준 |
| W3 | 3 | 보스 1 + 졸개 10 | **업소용 OB 생맥주 냉각기(보스)** + 한맥 캔, 생맥주잔, 필굿 캔 | 보스전. 양옆 부채꼴에서 오는 캔·생맥주잔으로 피버를 채워 냉각기 극딜 |
| W4 | 5 | 20 | 전 종류 혼합 (한맥·생맥주잔 비중 높음) | 부채꼴 전방위 압박 및 홀드 연사 활용 |
| W5+ | 6 | 25 + 3×(웨이브−5) | 전 종류 혼합 | 피버 연속 발동 구간 |

- **부채꼴(시점 모양) 방사형 스폰 및 접근**:
  - 배경 화면(카메라 시점)은 정면에 고정하여 어지럼증을 방지한다.
  - 적의 등장 위치는 정면 가운데만이 아니라, 미니맵에 표시되는 **부채꼴 시야각 전체(반경 `R = 28m` 원호, 수평 각도 `θ = -36° ~ +36°`, 왼쪽 끝 ~ 가운데 ~ 오른쪽 끝 전체; 보스는 중앙 `±10°`)**에서 골고루 스폰된다(`X = 28 × sin(θ)`, `Z = -28 × cos(θ)`).
  - 모든 적은 스폰된 각도(`θ`)의 부채꼴 방사형 반지름 선을 따라 플레이어 정면(`R = 1.8m` 방어선)을 향해 사방에서 조여 들어온다.
- 웨이브 시작 0.4초 뒤 첫 적이 나오고, 처치 즉시 남은 수량에서 한 마리씩 보충한다. (보충 간격 0.6초)
- 이동 속도는 웨이브마다 5%씩 빨라지고 최대 40%까지 늘어난다.
- 클리어 조건은 남은 수량 0이고 필드에 적이 없는 것이다.
- 휴식 5초 동안 탄이 가득 차고 영점 재조정을 안내한다. 이때도 아이템은 획득할 수 있다.

### 5.9 보스전 (웨이브 3 — 업소용 OB 생맥주 냉각기)

- 보스는 웨이브 3에 한 번 등장한다. 먼저 나오고 졸개가 부채꼴 좌우에서 뒤를 따른다.
- 보스 체력은 30이다. 한 번 적중에 1, 화력 강화(카스 화이트) 중에는 2씩 깎인다.
- 상단에 보스 체력 바를 보여주고, 보스 격파 시 큰 파편·거품 연출과 500점을 준다.

### 6.1 3D 스테이지 배경 및 1인칭 발사대

  - 플레이어 앞 `1.8m`에는 원목과 황동으로 마감된 **바 카운터 방어선**이 놓이고, 부채꼴 양옆 외곽에는 구리 맥주 숙성 탱크와 OB맥주 브랜드 네온사인이 배치된다.

### 6.3 드롭 아이템 (4종)

- 적 처치 시 40% 확률로 드롭된다. 네 종류가 같은 확률이다.
- 6초 뒤 사라지고, 마지막 1.5초는 깜빡인다. 플레이어 쪽으로 초당 1.5m씩 천천히 다가온다.
- 적과 같은 방식으로 쏴서 얻는다. 판정 반경은 0.5m다.
- 같은 효과를 다시 얻으면 지속시간이 갱신된다. 보호막은 중복되지 않는다.

| --- | --- | --- |

| **카스 0.0** | 시안 블루 캔 | 8초간 연사 간격 0.125초 → 0.06초 |

| **보호막** | 파란 OB맥주 플라스틱 상자 | 피격 1회 완전 방어. 맞기 전까지 유지 |

## 7. 화면 구성

### 7.1 PC 화면 (16:9 풀스크린 3D + 오버레이 HUD)

- **대기(QR) 화면**:
  - 좌측: 세션 QR 코드(5분 유효) + 6자리 코드 + 연결 안내 + `[PC 마우스/키보드로 바로 시작]` 버튼
  - 우측: **명예의 전당 TOP 5 랭킹 보드** (순위, 닉네임, 최고 점수, 도달 웨이브)
- **로그인/영점 안내 화면**:
  - 폰 접속 시 `"🍺 [닉네임]님 연결됨! (최고 기록: N점)"` 표시 (신규 회원이면 `"폰 화면에서 닉네임을 입력해주세요"` 안내)
  - 로그인 완료 후 `"휴대폰 윗부분을 모니터 중앙 과녁에 겨누고(화면은 좌측) 영점을 맞춰주세요"` 가이드 표시
- **인게임 HUD**:
  - **좌상단**: 플레이어 닉네임, 체력 10칸, 현재 점수( 및 개인 최고 점수)
  - **상단 중앙**: 웨이브 배너(2초), 보스가 있을 때 보스 생맥주 냉각기 체력 바
  - **우상단**: 남은 탄(자동 재장전 중에는 `자동 장전 중...`, 피버 중 `∞`), 활성 효과와 남은 시간, 연결 지연(ms)
  - **중앙**: 조준선, 바깥 피버 게이지 링(100% 완충 시 금색 점멸 및 `"더블터치로 FEVER 발동!"` 표시), 1.2초 자동 재장전 막대. `PERFECT / GREAT / GOOD` 문구는 조준선 위에 0.8초, 콤보 배너는 상단에 1.4초 보여준다.
  - **우하단 미니맵**: 정면 시야각 부채꼴, 28m 범위, 10m와 20m 눈금. 부채꼴 전체에서 몰려오는 지상 적(채운 원), 공중 적(속 빈 원), 보스(큰 원), 아이템(사각형)을 실시간 표시한다.
- **결과 화면**: 플레이어 닉네임, 도달 웨이브, 최종 점수(신기록 달성 배지), 최고 콤보, 처치 수, **PERFECT 비율(%) 및 GREAT 이상 비율(%)**, **TOP 5 랭킹 보드(내 순위 하이라이트)**, 다시 시작 버튼.

### 7.2 스마트폰 화면 (권총 파지 85:15 통합 터치 컨트롤러)

1. **화면 1 — 센서 권한 허용 및 자동 로그인 / 신규 닉네임 입력**:
   - 폰 고유번호(`deviceId`)를 조회해 **신규 회원이면 `닉네임 입력창(2~10자)`** 노출, **기존 회원이면 `"반갑습니다, [닉네임]님!"` 자동 로그인** 처리.
   - 센서 권한 허용(iOS 필수) 버튼 터치 후 권총 파지 자세 안내로 이동.
2. **화면 2 — 권총 파지 전투 컨트롤러 (앞쪽 15% 영점 : 몸쪽 85% 통합 터치 영역)**:
   - 휴대폰 **윗부분이 모니터**를 향하고 **액정 화면이 좌측**을 바라보는 권총 파지에 맞춰 구성한다(가로 시선 90° 회전 텍스트 적용).
   - **앞쪽 끝단 15% (모니터 쪽 상단)**: 연결 상태(ms), 탄창(`8/10`), **`[🎯 정면 영점 재설정]` 버튼** 배치.
   - **중앙~몸쪽 85% 전체 (엄지/반대손 통합 터치 패드)**:
     - 폰 화면을 안 보고도 엄지나 반대손으로 아무 곳이나 만져서 조작하는 단일 통합 영역:
       - **위로 손목 스냅**: 단발 사격
       - **꾸욱 누르기 (0.25초 이상 홀드)**: 연사 사격
       - **두 번 터치 (0.3초 이내 더블탭)**: **FEVER 발동** (피버 게이지 100% 완충 시 화면 전체가 금색으로 점멸하며 더블탭 대기 상태를 알림)
       - **자동 재장전**: 10발 소진 시 아무 조작 없이도 1.2초 자동 재장전 진행
