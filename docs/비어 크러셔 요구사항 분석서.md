## 1. 프로젝트 개요 및 기획 목표

- **프로젝트명**: 비어 크러셔 (Beer Crusher)
- **장르**: 1인칭 고정 시점 3D 아케이드 모션 슈팅
- **플랫폼**: PC 모니터 (Three.js 3D 렌더링, Web Audio) + 스마트폰 브라우저 (권총 파지 무선 모션 컨트롤러)
- **핵심 기획 목표**:
  1. **설치 없는 즉각성**: 별도 앱 다운로드 없이 QR 코드 스캔으로 5초 만에 연결되어 즉시 플레이.
  2. **체감형 오락실 손맛**: 스마트폰을 권총처럼 쥐고 모니터를 겨누어 쏘는 에어 포인팅 및 손목을 '휙!' 젖히는 액티브 스킬.
  3. **로그라이크 성장 재미**: 3종 무기 아키타입(샷건/리볼버/개틀링)의 4단계 진화 및 웨이브 클리어와 중간 지점에서 Combat Freeze 상태에 격발 선택하는 보상 카드 9종(무작위 3장).
  4. **스트레스 제로 아케이드 슈팅**: 조준경과 피격 판정의 1:1 일치, 정밀도 데미지 배율(0.5x/1.0x/2.0x) 도입, 판정 범위 축소로 난사 억제(누르고 쏘기 피해 감소, 긴 장전), MISS 점수·콤보 페널티 없음, 모바일/PC 공통 홀드 자동 연발(`투두두두`), 보스 10m 안전 거리 확보.

## 2. 사용자 역할 및 핵심 유저 스토리

1. **신규 플레이어**:
   - PC 화면의 QR 코드를 폰으로 스캔 ➔ 닉네임(2~10자)을 폰에서 입력 ➔ 즉시 자동 회원 등록 및 로비 환영 배너 출력.
2. **재방문 플레이어**:
   - QR 스캔 즉시 폰 고유번호(`deviceId`)를 인식해 별도 입력 없이 자동 로그인 ➔ 개인 최고 기록(`최고 점수 · 최고 웨이브`) 자동 로드.
3. **전투 플레이어**:
   - 권총 파지 자세에서 폰을 움직여 조준선 제어 ➔ 화면 터치 홀드 또는 PC 마우스 좌클릭 홀드로 호쾌한 자동 연발 ➔ 정밀 사격(PERFECT) 및 적 처치(KILL)로 피버 충전 ➔ 피버 100% 시 더블탭으로 4초 무제한 탄창 자동 연사 ➔ 위기 시 손목을 '휙!' 젖혀 광역 스킬 시전.
4. **킬 게이지 보상 선택**:
   - 웨이브를 클리어하거나 4·6웨이브 중간 킬 수를 채우면 전장이 안전하게 멈추고(Combat Freeze), 공중에 떠오른 3D 보상 카드 9종 중 무작위 3장에서 원하는 카드를 새로 누른 사격으로 선택(Shoot-to-Select).

## 3. 기능 요구사항 (Functional Requirements)

### 3.1 연결 및 플레이어 인증 (`FR-CON`, `FR-AUTH`)
| ID | 요구사항 명세 | 검증 기준 |
| :--- | :--- | :--- |
| **FR-CON-01** | PC 호스트와 모바일 컨트롤러는 1:1 WebSocket 세션 룸으로 실시간 연결되어야 한다. | 다중 접속 차단 및 세션 격리 |
| **FR-CON-02** | 로컬 HTTPS(Vite basicSsl) 환경에서 모바일 브라우저의 센서 권한을 정상 획득해야 한다. | iOS Safari 및 Android Chrome 센서 작동 |
| **FR-CON-03** | 컨트롤러의 센서 패킷은 60Hz 빈도로 전송되며 레이턴시는 50ms 미만을 유지해야 한다. | 인게임 HUD 패킷 레이턴시 표기 |
| **FR-AUTH-01** | 폰 고유번호(`deviceId`) 기반 자동 로그인 및 신규 플레이어 닉네임 등록을 지원해야 한다. | DB 영구 저장 및 랭킹 반영 |

### 3.2 조작 및 모션 트래킹 (`FR-INP`)
| ID | 요구사항 명세 | 검증 기준 |
| :--- | :--- | :--- |
| **FR-INP-01** | 스마트폰 상단(+Y축)이 모니터를 향하고 화면(+Z축)이 좌측을 바라보는 **권총 파지**를 표준으로 한다. | `GunGripTracker` 오리엔테이션 투영 |
| **FR-INP-02** | 폰 앞쪽 15% 영점 버튼 터치 시 현재 총구 자세를 화면 중앙(`0, 0`)으로 실시간 재보정해야 한다. | 즉시 영점 캘리브레이션 |
| **FR-INP-03** | 손목을 위로 빠르게 튕기는 가속도 제스처(`>= 12 m/s²`) 시 무기별 액티브 스킬이 발동되어야 한다. | `detectSnapFire` 스킬 트리거 |
| **FR-INP-04** | 스냅 스킬 시전 시 손목 반동으로 에임이 천장으로 튀지 않도록 **350ms 동안 에임을 고정**해야 한다. | `aimFreeze` 동작 및 조준선 안정성 |
| **FR-INP-05** | 모바일 화면 180ms 터치 홀드 및 PC 마우스 좌클릭 홀드 시 무기 발사 간격(`fireIntervalMs`) 기반 자동 연발(`투두두두`)을 지원해야 한다. | 홀드 유지 시 무기별 고유 주기로 연속 격발 |

### 3.3 무기 및 전투 시스템 (`FR-WPN`)
| ID | 요구사항 명세 | 검증 기준 |
| :--- | :--- | :--- |
| **FR-WPN-01** | 3종 무기(🪠 샷건, 🍾 리볼버, 🍺 개틀링)별로 고유한 비주얼 조준경 HUD를 렌더링해야 한다. | 샷건 120px 링, 리볼버 76px 십자선, 개틀링 88px 톱니 |
| **FR-WPN-02** | 조준 정확도에 따라 데미지 배율(PERFECT 2.0배, GREAT 1.0배, GOOD 0.5배)을 차등 적용하고, 빗맞춤(MISS) 시 콤보 감점/피버 차감은 없되 탄약과 긴 장전이 손해가 되도록 판정 범위(x0.75, 화면비 보정)와 연사/장전 규칙을 두어야 한다. | 판정별 데미지 수식, MISS 점수·피버 페널티 0, 판정 범위 계산 |
| **FR-WPN-03** | 각 무기는 Lv.1부터 Lv.4(MAX)까지 4단계 3D 외형 진화 및 화력/스펙 강화를 지원해야 한다. | 보상 카드 선택 시 실시간 외형 교체 |
| **FR-WPN-04** | 피버 충전은 PERFECT 적중(+2%) 및 적 처치(+4%)로 누적되며(금색 캔 +30%, 피버 부스터 카드 +50%), 100% 달성 시 더블탭/스페이스바로 4초간 무제한 탄창 자동 연사(연사 속도·피해는 평소와 같고 명중 점수 1.5배)가 발동되어야 한다. 보스 몸통 타격은 피버를 충전하지 않는다. | 피버 충전 공식 및 4초 무제한 탄창 피버 |
| **FR-WPN-05** | 누르고 있는 연사(`hold`)는 피해가 줄고(샷건·리볼버 ×0.6, 개틀링 ×0.85) 탭 사격과 피버 자동 발사는 감소가 없어야 하며, 카드 선택은 새로 누른 입력으로만 가능해야 한다. | `ShotSource` 별 피해/선택 검증 |

| **FR-MON-02** | 모든 몬스터 상단에 100% 슬림 연속 체력 게이지 바를 렌더링해야 한다. (단, 1HP 캔은 기본 숨김, 0.5x 피격 등으로 체력이 깎이면 즉시 노출) | 슬림 게이지 바 및 피격 1HP 캔 실시간 노출 |

## 4. 비기능 요구사항 (Non-Functional Requirements)

- **NFR-PERF (성능)**: 몬스터 15마리 이상 및 파티클 폭발 시에도 PC 브라우저 60fps 렌더링 유지.
- **NFR-LATENCY (지연 시간)**: 동일 Wi-Fi 네트워크 환경에서 센서 프레임 처리 지연 50ms 미만.
- **NFR-RELIABILITY (견고성)**: WebSocket 연결 일시 단절 시 30초 재접속 유예 카운트다운 및 안전 복구.
- **NFR-COMPATIBILITY (호환성)**: 모바일 센서 없이도 PC 마우스 좌/우클릭(홀드 자동 연발 지원) 및 키보드(`R`, `Space`, `C`, `1/2/3`)로 100% 동일한 플레이 지원.
